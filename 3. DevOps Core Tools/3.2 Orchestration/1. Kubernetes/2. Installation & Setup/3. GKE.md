## GKE — Google Kubernetes Engine

**GKE (Google Kubernetes Engine)** is a **managed Kubernetes service provided by Google Cloud (GCP)**. It allows you to run Kubernetes clusters on Google Cloud without manually managing the Kubernetes control plane.

### Simple Architecture

```text
                  Google Cloud (GCP)
                         │
                    ┌────┴────┐
                    │   GKE   │
                    │         │
                    │ Control │ ← Google manages
                    │  Plane  │
                    └────┬────┘
                         │
                 ┌───────┴───────┐
                 │   Node Pool   │
                 │               │
                 │ ┌────┐ ┌────┐ │
                 │ │Pod │ │Pod │ │
                 │ └────┘ └────┘ │
                 └───────────────┘
```

### What does Google manage?

Google manages the **Kubernetes control plane**.

You manage/configure:

* Applications and Pods
* Deployments
* Services
* ConfigMaps and Secrets
* Networking
* Storage
* RBAC
* Node pools, depending on the GKE mode

### GKE Modes

**1. Autopilot**

Google manages more of the underlying infrastructure and node management for you.

> Focus mainly on your **workloads**, rather than managing nodes.

**2. Standard**

You have more control over the cluster infrastructure and node pools.

> Useful when you need more **control and customization**.

### GKE integrates with Google Cloud

Common services:

```text
GKE
│
├── VPC
├── Cloud Load Balancing
├── Artifact Registry
├── Cloud Monitoring
├── Cloud Logging
├── Google Cloud Storage
└── IAM
```

### GKE vs EKS vs AKS

| Service | Cloud Provider | Managed Kubernetes |
| ------- | -------------- | ------------------ |
| **EKS** | AWS            | AWS                |
| **AKS** | Azure          | Microsoft          |
| **GKE** | Google Cloud   | Google             |

### ⭐ Interview Answer

> **GKE is Google's managed Kubernetes service on Google Cloud. Google manages the Kubernetes control plane, while we manage our applications and, depending on the mode, the underlying node infrastructure.**

**Easy to remember:**

> **EKS = AWS + Kubernetes**
> **AKS = Azure + Kubernetes**
> **GKE = Google Cloud + Kubernetes**
