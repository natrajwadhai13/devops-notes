## AKS — Azure Kubernetes Service

**AKS (Azure Kubernetes Service)** is a **managed Kubernetes service provided by Microsoft Azure**. It allows you to run Kubernetes clusters in Azure without manually managing the Kubernetes control plane.

### Simple Architecture

```text
                    Azure
                      │
                 ┌────┴────┐
                 │   AKS   │
                 │         │
                 │ Control │
                 │ Plane   │ ← Azure manages
                 └────┬────┘
                      │
              ┌───────┴────────┐
              │   Node Pool    │ ← You manage
              │                │
              │ ┌────┐ ┌────┐ │
              │ │Pod │ │Pod │ │
              │ └────┘ └────┘ │
              └────────────────┘
```

### What Azure manages?

Azure manages the **AKS control plane**, including Kubernetes control-plane components.

You are responsible for things such as:

* Applications and Pods
* Deployments
* Services
* ConfigMaps and Secrets
* Networking configuration
* Storage
* RBAC
* Monitoring
* Node pools, depending on the configuration

### AKS integrates with Azure

Common Azure services used with AKS:

```text
AKS
│
├── Azure Virtual Network (VNet)
├── Azure Load Balancer
├── Azure Container Registry (ACR)
├── Azure Monitor
├── Azure Storage
├── Microsoft Entra ID
└── Azure Managed Identity
```

### AKS vs EKS

| AKS                          | EKS                          |
| ---------------------------- | ---------------------------- |
| Microsoft Azure              | AWS                          |
| Azure Kubernetes Service     | Elastic Kubernetes Service   |
| Uses Azure services          | Uses AWS services            |
| ACR commonly used for images | ECR commonly used for images |
| Azure Monitor                | CloudWatch                   |
| Entra ID                     | IAM                          |

### ⭐ Interview Answer

> **AKS is Microsoft's managed Kubernetes service on Azure. Azure manages the Kubernetes control plane, while we manage our applications, workloads, and node pools depending on the configuration.**

**Easy to remember:**

> **AKS = Kubernetes + Azure Managed Control Plane**
