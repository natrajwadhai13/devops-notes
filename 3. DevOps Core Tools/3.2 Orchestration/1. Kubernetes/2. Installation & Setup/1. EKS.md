## EKS — Elastic Kubernetes Service

**Amazon EKS (Elastic Kubernetes Service)** is a **managed Kubernetes service provided by AWS**. It allows you to run Kubernetes clusters on AWS without managing the Kubernetes **control plane** yourself.

### Simple Architecture

```text
                    AWS
                     │
              ┌──────┴──────┐
              │     EKS     │
              │             │
              │ Control     │
              │ Plane       │ ← AWS manages
              └──────┬──────┘
                     │
              ┌──────┴──────┐
              │ Worker Nodes│ ← You manage
              ├─────────────┤
              │    Pods     │
              │ Applications│
              └─────────────┘
```

### What AWS manages?

AWS manages the **EKS control plane**, including major Kubernetes control-plane components and their availability.

You are generally responsible for:

* Worker nodes / compute
* Pods and applications
* Deployments
* Services
* Networking configuration
* Storage
* Security/RBAC
* Monitoring

### EKS Worker Node Options

You can run workloads using:

* **Managed Node Groups** → AWS helps manage EC2 worker nodes
* **Self-managed nodes** → You manage the EC2 nodes yourself
* **AWS Fargate** → Run Pods without managing worker EC2 servers

### Common EKS Components

```text
EKS
│
├── Control Plane
│
├── Worker Nodes
│   ├── EC2
│   └── Fargate
│
├── VPC
├── IAM
├── Load Balancer
├── EBS / EFS
└── CloudWatch
```

### EKS vs Kubernetes

| Kubernetes                            | EKS                                  |
| ------------------------------------- | ------------------------------------ |
| Open-source platform                  | AWS managed Kubernetes service       |
| Can run anywhere                      | Runs on AWS                          |
| You can manage control plane yourself | AWS manages control plane            |
| Need to choose/setup infrastructure   | AWS provides managed service options |

### ⭐ Interview Answer

> **EKS is AWS's managed Kubernetes service. AWS manages the Kubernetes control plane, while we manage our applications, workloads, and depending on the setup, worker nodes or compute resources.**

**Easy to remember:**

> **EKS = Kubernetes + AWS Managed Control Plane**
