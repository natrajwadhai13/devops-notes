# Helm Templates

Helm uses Go templates to generate Kubernetes YAML.

## Basic Expression

```yaml
replicas: {{ .Values.replicaCount }}
```

## Important Objects

| Object | Purpose |
|---|---|
| `.Values` | Values from configuration |
| `.Release` | Release information |
| `.Chart` | Chart metadata |
| `.Capabilities` | Cluster/API capabilities |

Examples:

```yaml
{{ .Release.Name }}
{{ .Chart.Name }}
{{ .Values.image.repository }}
```

## if / else

```yaml
{{- if .Values.ingress.enabled }}
apiVersion: networking.k8s.io/v1
kind: Ingress
...
{{- end }}
```

## range

```yaml
{{- range .Values.env }}
- name: {{ .name }}
  value: {{ .value | quote }}
{{- end }}
```

## with

`with` changes the current context.

```yaml
{{- with .Values.service }}
port: {{ .port }}
type: {{ .type }}
{{- end }}
```

## Variables

```yaml
{{- $name := .Release.Name }}
```

## Whitespace

Common forms:

```text
{{ ... }}
{{- ... }}
{{ ... -}}
{{- ... -}}
```

Use whitespace control carefully so the rendered YAML remains valid.

## Template Validation

```bash
helm lint ./mychart
helm template myrelease ./mychart
helm template myrelease ./mychart --debug
```
