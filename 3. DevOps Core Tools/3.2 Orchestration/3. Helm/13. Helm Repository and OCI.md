# Helm Repository and OCI

## Traditional Helm Repository

A traditional repository provides charts and an index.

```bash
helm repo add bitnami https://charts.bitnami.com/bitnami
helm repo update
helm search repo nginx
helm pull bitnami/nginx
```

## OCI

Helm also supports OCI registries for storing and distributing charts.

Typical flow:

```text
Package chart
   ↓
Login to registry
   ↓
Push chart
   ↓
Pull / install chart
```

## Package

```bash
helm package ./mychart
```

## OCI Login

```bash
helm registry login <registry>
```

## Push

```bash
helm push mychart-0.1.0.tgz oci://<registry>/<repository>
```

## Pull

```bash
helm pull oci://<registry>/<repository>/mychart --version 0.1.0
```

## Traditional Repository vs OCI

| Traditional Repository | OCI |
|---|---|
| Chart repository + index | OCI registry |
| `helm repo add` | Registry login |
| `helm search repo` | Registry-based artifact discovery |
| `helm pull` from repo | `helm pull` from `oci://` |

## Production Considerations

- Authenticate securely
- Use immutable/versioned charts
- Restrict registry permissions
- Scan charts/images where supported
- Avoid exposing credentials in CI logs
