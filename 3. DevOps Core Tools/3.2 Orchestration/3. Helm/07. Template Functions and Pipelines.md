# Template Functions and Pipelines

## Pipeline

A pipeline passes the output of one function into the next.

```bash
{{ .Values.name | quote }}
```

## Most Useful Functions

### quote

```bash
name: {{ .Values.name | quote }}
```

### default

```bash
replicas: {{ .Values.replicaCount | default 1 }}
```

### required

```bash
image: {{ required "image.repository is required" .Values.image.repository }}
```

### tobash + nindent

Very common for Kubernetes configuration:

```bash
resources:
{{- tobash .Values.resources | nindent 2 }}
```

### indent

```bash
{{ .Values.config | tobash | indent 2 }}
```

### upper -lower

```bash
{{ .Values.environment | upper }}
```

### replace

```bash
{{ .Values.name | replace "_" "-" }}
```

### printf

```bash
{{ printf "%s-%s" .Release.Name .Chart.Name }}
```

### list / dict

Used when constructing data for reusable templates.

## Function vs Pipeline

```text
Function:
quote .Values.name

Pipeline:
.Values.name | quote
```

## Interview Priority

Know these well:

`quote`, `default`, `required`, `tobash`, `nindent`, `include`, `printf`, `replace`.
