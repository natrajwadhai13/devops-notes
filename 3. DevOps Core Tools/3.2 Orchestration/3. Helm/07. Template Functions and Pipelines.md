# Template Functions and Pipelines

## Pipeline

A pipeline passes the output of one function into the next.

```yaml
{% raw %}
{{ .Values.name | quote }}
```
{% endraw %}

## Most Useful Functions

### quote

```yaml
{% raw %}
name: {{ .Values.name | quote }}
```
{% endraw %}

### default

```yaml
{% raw %}
replicas: {{ .Values.replicaCount | default 1 }}
```
{% endraw %}

### required

```yaml
{% raw %}
image: {{ required "image.repository is required" .Values.image.repository }}
```
{% endraw %}

### toYaml + nindent

Very common for Kubernetes configuration:

```yaml
{% raw %}
resources:
{{- toYaml .Values.resources | nindent 2 }}
```
{% endraw %}

### indent

```yaml
{% raw %}
{{ .Values.config | toYaml | indent 2 }}
```
{% endraw %}

### upper / lower

```yaml
{% raw %}
{{ .Values.environment | upper }}
```
{% endraw %}

### replace

```yaml
{% raw %}
{{ .Values.name | replace "_" "-" }}
```
{% endraw %}

### printf

```yaml
{% raw %}
{{ printf "%s-%s" .Release.Name .Chart.Name }}
```
{% endraw %}

### list / dict

Used when constructing data for reusable templates.

## Function vs Pipeline

```text
Function:
quote .Values.name

Pipeline:
.Values.name | quote
```

## Interview Priority

Know these well:

`quote`, `default`, `required`, `toYaml`, `nindent`, `include`, `printf`, `replace`.
