## Priority

**Must know:** Fundamentals, chart structure, values, templates, commands, releases, validation/debugging.

**Production:** Dependencies, hooks, OCI, secrets, Kubernetes resources, CI/CD/GitOps.

**Interview:** Be able to explain the Helm → template → Kubernetes → release flow and write the common commands without referring to notes.
