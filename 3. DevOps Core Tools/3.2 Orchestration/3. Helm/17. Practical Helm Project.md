# Practical Helm Project

## Goal

Create and deploy a simple Apache application using Helm.

## Step 1 — Create Chart

```bash
helm create apache
cd apache
```

## Step 2 — Configure values.yaml

```yaml
replicaCount: 2

image:
  repository: httpd
  tag: "2.4"

service:
  type: ClusterIP
  port: 80
```

## Step 3 — Inspect the Chart

```bash
helm lint .
helm template apache .
```

## Step 4 — Install

```bash
helm install apache .
```

Or use a namespace:

```bash
helm upgrade --install apache .   -n web   --create-namespace
```

## Step 5 — Verify

```bash
helm status apache -n web
kubectl get all -n web
kubectl get pods -n web
```

## Step 6 — Upgrade

Change the replica count:

```yaml
replicaCount: 3
```

Then:

```bash
helm upgrade apache . -n web
helm history apache -n web
```

## Step 7 — Rollback

```bash
helm rollback apache 1 -n web
```

## Step 8 — Debug

```bash
helm get manifest apache -n web
helm get values apache -n web
kubectl describe pod -n web <pod>
kubectl logs -n web <pod>
```

## Step 9 — Remove

```bash
helm uninstall apache -n web
```

## Interview Explanation

> I created a Helm chart for Apache, configured replicas and image values, validated it using lint and template, deployed it with `helm upgrade --install`, verified Kubernetes resources, upgraded the release, checked revision history, and rolled back when required.
