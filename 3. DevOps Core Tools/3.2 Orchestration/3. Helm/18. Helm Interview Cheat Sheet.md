# Helm Interview Cheat Sheet

## 1. What is Helm?

Helm is the package manager for Kubernetes. It uses charts and templates to package and deploy applications and manages them as releases.

## 2. What is a Chart?

A reusable package containing chart metadata, values, templates, and optional dependencies.

## 3. What is a Release?

A deployed instance of a chart.

## 4. Chart vs Release?

Chart = package/template.

Release = installed instance.

## 5. Chart.yaml vs values.yaml?

`Chart.yaml` = chart metadata.

`values.yaml` = default configuration.

## 6. What is the templates directory?

It contains Kubernetes manifests with Helm template expressions.

## 7. How do you override values?

```bash
helm install app ./chart -f values-prod.yaml
helm install app ./chart --set replicaCount=3
```

## 8. How do you upgrade?

```bash
helm upgrade app ./chart
```

For install-or-upgrade automation:

```bash
helm upgrade --install app ./chart
```

## 9. How do you rollback?

```bash
helm history app
helm rollback app 2
```

## 10. How do you debug?

```bash
helm lint ./chart
helm template app ./chart
helm install app ./chart --dry-run --debug
helm status app
helm get all app
kubectl describe pod <pod>
kubectl logs <pod>
```

## 11. What happened to Tiller?

Tiller was used by Helm 2. Helm 3 removed Tiller and uses the Kubernetes API directly.

## 12. What are Helm Hooks?

Hooks run Kubernetes resources at lifecycle events such as pre-install or post-upgrade.

## 13. What are Dependencies?

Dependencies allow a parent chart to use subcharts such as Redis or PostgreSQL.

## 14. Helm Repository vs OCI?

A traditional repository distributes charts through a chart repository/index. OCI stores charts as OCI artifacts in a registry.

## 15. Helm with GitOps?

A GitOps controller such as Argo CD can render Helm charts and continuously reconcile Kubernetes with the desired state stored in Git.

## 16. One-Minute Helm Flow

```text
Chart
  ↓
values.yaml
  ↓
Templates
  ↓
Rendered Kubernetes YAML
  ↓
Kubernetes API
  ↓
Helm Release
  ↓
Upgrade / History / Rollback
```
