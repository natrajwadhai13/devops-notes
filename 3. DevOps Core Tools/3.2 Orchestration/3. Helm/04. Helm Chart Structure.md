# Helm Chart Structure

## Create a Chart

```bash
helm create myapp
```

Typical structure:

```text
myapp/
├── Chart.yaml
├── values.yaml
├── charts/
├── templates/
│   ├── deployment.yaml
│   ├── service.yaml
│   ├── ingress.yaml
│   ├── configmap.yaml
│   ├── serviceaccount.yaml
│   ├── tests/
│   └── _helpers.tpl
└── .helmignore
```

## Chart.yaml

Contains chart metadata.

```yaml
apiVersion: v2
name: myapp
description: My application
type: application
version: 0.1.0
appVersion: "1.0.0"
```

**Important:** `version` is the chart version; `appVersion` describes the application version.

## values.yaml

Contains default configuration.

```yaml
replicaCount: 2

image:
  repository: nginx
  tag: "1.27"

service:
  type: ClusterIP
  port: 80
```

## templates/

Contains Kubernetes manifests with Helm expressions.

## charts/

Stores packaged dependencies/subcharts.

## `_helpers.tpl`

Contains reusable named templates such as names and labels.

## .helmignore

Controls files excluded when packaging the chart.
