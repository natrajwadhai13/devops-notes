# 3. Helm Commands

## Important Points ⭐

1. **`helm version`** — Check Helm version
2. **`helm help`** — Get help
3. **`helm repo`** — Manage Helm repositories
4. **`helm search`** — Search for charts
5. **`helm install`** — Install a chart
6. **`helm list`** — List releases
7. **`helm status`** — Check release status
8. **`helm upgrade`** — Upgrade a release
9. **`helm rollback`** — Roll back a release
10. **`helm history`** — View release history
11. **`helm uninstall`** — Remove a release
12. **`helm get`** — Get release information
13. **`helm show`** — Inspect chart information
14. **`helm create`** — Create a new chart
15. **`helm lint`** — Validate a chart
16. **`helm template`** — Render templates locally
17. **`helm dependency`** — Manage chart dependencies
18. **`helm package`** — Package a chart
19. **`helm pull`** — Download a chart

---

## 1. `helm version`

Checks the installed Helm version.

```bash
helm version
```

Example:

```text
version.BuildInfo{
  Version:"v3.x.x"
}
```

Useful for verifying that Helm is installed correctly.

---

## 2. `helm help`

Displays Helm command help.

```bash
helm help
```

For a specific command:

```bash
helm install --help
```

---

# Repository Commands

## 3. `helm repo add`

Adds a Helm repository.

```bash
helm repo add bitnami https://charts.bitnami.com/bitnami
```

---

## 4. `helm repo list`

Lists configured Helm repositories.

```bash
helm repo list
```

---

## 5. `helm repo update`

Updates the local information about charts available in repositories.

```bash
helm repo update
```

---

## 6. `helm repo remove`

Removes a repository.

```bash
helm repo remove bitnami
```

---

# Search Commands

## 7. `helm search repo`

Searches charts in configured repositories.

```bash
helm search repo nginx
```

Example:

```text
bitnami/nginx
```

---

## 8. `helm search hub`

Searches Helm charts from Artifact Hub.

```bash
helm search hub nginx
```

---

# Installation Commands

## 9. `helm install` ⭐⭐⭐⭐⭐

Installs a Helm Chart and creates a **Release**.

```bash
helm install myapp ./mychart
```

Here:

```text
myapp     → Release name
mychart   → Chart
```

Using a repository chart:

```bash
helm install my-nginx bitnami/nginx
```

---

## 10. Install with Custom Values

Using a values file:

```bash
helm install myapp ./mychart -f values-prod.yaml
```

Using `--set`:

```bash
helm install myapp ./mychart --set replicaCount=3
```

Multiple values:

```bash
helm install myapp ./mychart \
  --set replicaCount=3 \
  --set image.tag=1.2.0
```

---

# Release Commands

## 11. `helm list` ⭐⭐⭐⭐

Lists Helm releases.

```bash
helm list
```

List releases from all namespaces:

```bash
helm list -A
```

List releases from a specific namespace:

```bash
helm list -n dev
```

---

## 12. `helm status` ⭐⭐⭐⭐

Shows the status of a release.

```bash
helm status myapp
```

With namespace:

```bash
helm status myapp -n dev
```

---

## 13. `helm upgrade` ⭐⭐⭐⭐⭐

Updates an existing Helm release.

```bash
helm upgrade myapp ./mychart
```

With new values:

```bash
helm upgrade myapp ./mychart -f values-prod.yaml
```

Example:

```bash
helm upgrade myapp ./mychart --set replicaCount=5
```

---

## 14. `helm upgrade --install`

Very useful in **CI/CD pipelines**.

```bash
helm upgrade --install myapp ./mychart
```

Meaning:

```text
Release exists?
       |
   Yes ─────→ Upgrade
       |
   No ───────→ Install
```

This command is extremely common in DevOps.

---

# Rollback Commands

## 15. `helm history` ⭐⭐⭐⭐⭐

Shows the revision history of a release.

```bash
helm history myapp
```

Example:

```text
REVISION   STATUS
1          deployed
2          deployed
3          deployed
```

---

## 16. `helm rollback` ⭐⭐⭐⭐⭐

Rolls a release back to a previous revision.

```bash
helm rollback myapp 2
```

Here:

```text
myapp → Release
2     → Revision
```

Check the result:

```bash
helm history myapp
```

---

# Uninstall Commands

## 17. `helm uninstall` ⭐⭐⭐⭐

Removes a Helm release.

```bash
helm uninstall myapp
```

Specific namespace:

```bash
helm uninstall myapp -n dev
```

Important:

**Uninstalling a release is different from deleting the Helm Chart.**

---

# Get Commands

## 18. `helm get` ⭐⭐⭐⭐

`helm get` retrieves information about an installed release.

### Get all information

```bash
helm get all myapp
```

### Get values

```bash
helm get values myapp
```

Get all values including defaults:

```bash
helm get values myapp -a
```

### Get manifest

```bash
helm get manifest myapp
```

### Get release notes

```bash
helm get notes myapp
```

---

# Chart Inspection Commands

## 19. `helm show`

Used to inspect a chart before installing it.

### Show chart information

```bash
helm show chart bitnami/nginx
```

### Show default values

```bash
helm show values bitnami/nginx
```

### Show README

```bash
helm show readme bitnami/nginx
```

### Show all information

```bash
helm show all bitnami/nginx
```

---

# Chart Creation Commands

## 20. `helm create` ⭐⭐⭐⭐

Creates a new Helm Chart structure.

```bash
helm create mychart
```

It creates:

```text
mychart/
├── Chart.yaml
├── values.yaml
├── charts/
├── templates/
└── .helmignore
```

This command is important when creating your own Helm Chart.

---

# Validation and Debugging

## 21. `helm lint` ⭐⭐⭐⭐⭐

Checks a Helm Chart for possible problems.

```bash
helm lint ./mychart
```

Example:

```text
1 chart(s) linted, 0 chart(s) failed
```

---

## 22. `helm template` ⭐⭐⭐⭐⭐

Renders Helm templates into Kubernetes YAML **without installing them**.

```bash
helm template myapp ./mychart
```

This is extremely useful for debugging.

Using values:

```bash
helm template myapp ./mychart -f values-prod.yaml
```

---

## 23. `helm install --dry-run`

Simulates an installation without actually deploying resources.

```bash
helm install myapp ./mychart --dry-run
```

For debugging:

```bash
helm install myapp ./mychart --dry-run --debug
```

### Difference

```text
helm template
      ↓
Render templates locally

helm install --dry-run
      ↓
Simulate installation

helm install
      ↓
Actually deploy
```

---

# Dependency Commands

## 24. `helm dependency`

Used to manage dependencies of a Helm Chart.

Update dependencies:

```bash
helm dependency update
```

Build dependencies:

```bash
helm dependency build
```

List dependencies:

```bash
helm dependency list
```

---

# Packaging Commands

## 25. `helm package`

Packages a Helm Chart into a `.tgz` file.

```bash
helm package mychart
```

Example:

```text
mychart-0.1.0.tgz
```

This package can be uploaded to a Helm repository.

---

## 26. `helm pull`

Downloads a chart from a repository.

```bash
helm pull bitnami/nginx
```

Download and extract:

```bash
helm pull bitnami/nginx --untar
```

### ⭐ Interview Questions to Remember

**Q: What is the difference between `helm install` and `helm upgrade`?**
`helm install` creates a new release. `helm upgrade` updates an existing release.

**Q: What is `helm upgrade --install`?**
It installs the release if it doesn't exist; otherwise, it upgrades the existing release.

**Q: How do you validate a Helm Chart?**

```bash
helm lint ./mychart
```

**Q: How do you see the Kubernetes YAML generated by Helm?**

```bash
helm template myapp ./mychart
```

**Q: How do you roll back a Helm deployment?**

```bash
helm history myapp
helm rollback myapp <revision>
```

**Q: How do you check values used by a release?**

```bash
helm get values myapp
```

**Q: How do you see the deployed Kubernetes manifest?**

```bash
helm get manifest myapp
```
