## 1. Helm Installation

Helm is installed as a **CLI tool** on your local machine or DevOps server.

Helm does not need to be installed inside the Kubernetes cluster.

Architecture:

```text
Your Laptop / DevOps Server
        |
     Helm CLI
        |
 Kubernetes API Server
        |
 Kubernetes Cluster
```

---

## 2. Check Helm Version

After installation, verify the Helm version:

```bash
helm version
```

Example:

```text
version.BuildInfo{
  Version:"v3.x.x"
}
```

You can also check:

```bash
helm help
```

---

## 3. Helm Client Configuration

Helm uses your Kubernetes configuration to communicate with the cluster.

Usually, Helm uses the Kubernetes `kubeconfig` file:

```text
~/.kube/config
```

Check the current Kubernetes context:

```bash
kubectl config current-context
```

List available contexts:

```bash
kubectl config get-contexts
```

---

## 4. Kubernetes Cluster Requirement

Helm is primarily used to deploy applications to Kubernetes.

You should have access to a Kubernetes cluster such as:

* Minikube
* Kind
* Kubeadm cluster
* Amazon EKS
* Azure AKS
* Google GKE

Check cluster connectivity:

```bash
kubectl get nodes
```

Example:

```text
NAME       STATUS   ROLES
minikube   Ready    control-plane
```

---

## 5. Verify Kubernetes Connection

Before using Helm, make sure `kubectl` can communicate with Kubernetes.

Run:

```bash
kubectl cluster-info
```

Then:

```bash
kubectl get nodes
```

If these commands work, Helm can generally use the same Kubernetes context.

---

## 6. Add a Helm Repository

A Helm repository contains Helm Charts.

Example:

```bash
helm repo add bitnami https://charts.bitnami.com/bitnami
```

Check configured repositories:

```bash
helm repo list
```

Example:

```text
NAME      URL
bitnami   https://charts.bitnami.com/bitnami
```

---

## 7. Update Helm Repository

After adding a repository, update its chart information:

```bash
helm repo update
```

This downloads the latest repository index information.

Important distinction:

```bash
helm repo add
```

→ Adds a repository.

```bash
helm repo update
```

→ Updates the repository's chart information.

---

## 8. Search Helm Charts

Search charts available in configured repositories:

```bash
helm search repo nginx
```

Example:

```text
NAME              CHART VERSION
bitnami/nginx     ...
```

You can also search Artifact Hub:

```bash
helm search hub nginx
```

---

## 9. Install a Test Chart

After configuring a repository, you can install a chart.

Example:

```bash
helm install my-nginx bitnami/nginx
```

Here:

```text
my-nginx       → Release name
bitnami/nginx  → Chart
```

Check the release:

```bash
helm list
```

Check status:

```bash
helm status my-nginx
```

Check Kubernetes resources:

```bash
kubectl get pods
```

---

## 10. Uninstall Test Release

When testing is complete:

```bash
helm uninstall my-nginx
```

Verify:

```bash
helm list
```

The release should no longer appear.

---

## 11. Important Installation Commands

| Command            | Purpose                       |
| ------------------ | ----------------------------- |
| `helm version`     | Check Helm version            |
| `helm help`        | Show Helm help                |
| `helm repo add`    | Add Helm repository           |
| `helm repo list`   | List repositories             |
| `helm repo update` | Update repository information |
| `helm search repo` | Search charts                 |
| `helm install`     | Install a chart               |
| `helm list`        | List releases                 |
| `helm status`      | Check release status          |
| `helm uninstall`   | Remove a release              |

---

## 12. Basic Setup Flow ⭐⭐⭐⭐⭐

Remember this flow for interviews:

```text
Install Helm
     ↓
helm version
     ↓
Configure Kubernetes access
     ↓
kubectl get nodes
     ↓
helm repo add
     ↓
helm repo update
     ↓
helm search repo
     ↓
helm install
     ↓
helm list / helm status
     ↓
kubectl get pods
```

### Quick Interview Revision

**Does Helm need to be installed inside Kubernetes?**
→ No. Helm CLI runs outside the cluster and communicates with the Kubernetes API.

**What does Helm use to connect to Kubernetes?**
→ Kubernetes configuration/context, commonly through `kubeconfig`.

**How do you add a repository?**

```bash
helm repo add <name> <url>
```

**How do you update repository information?**

```bash
helm repo update
```

**How do you verify Helm?**

```bash
helm version
```

**How do you verify Kubernetes connectivity?**

```bash
kubectl get nodes
```
