# 4. Application Management

## 1. What is an Application?

In Argo CD, an **Application** represents the deployment of an application from a **Git repository to a Kubernetes cluster**.

It defines:

* **Source** → Git repository
* **Path** → Location of manifests/Helm chart
* **Destination** → Kubernetes cluster
* **Namespace** → Where application will run

```text
Git Repository
      |
      | Source
      v
 Argo CD Application
      |
      | Destination
      v
Kubernetes Cluster
```

## 2. Application YAML

Basic example:

```yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: my-app
  namespace: argocd
spec:
  project: default

  source:
    repoURL: https://github.com/user/devops-app.git
    targetRevision: main
    path: kubernetes

  destination:
    server: https://kubernetes.default.svc
    namespace: dev

  syncPolicy:
    automated: {}
```

## 3. Important Fields

| Field            | Purpose                      |
| ---------------- | ---------------------------- |
| `source`         | Git repository information   |
| `repoURL`        | Git repository URL           |
| `targetRevision` | Branch/tag/commit            |
| `path`           | Manifest/Helm chart location |
| `destination`    | Target Kubernetes cluster    |
| `namespace`      | Target namespace             |
| `syncPolicy`     | Controls synchronization     |

## 4. Sync

**Sync** means applying the desired configuration from Git to Kubernetes.

```text
Git = Desired State
        ↓
      Argo CD
        ↓
Kubernetes = Live State
```

If Git and Kubernetes are different:

```text
Status: OutOfSync
```

After synchronization:

```text
Status: Synced
```

## 5. Auto-Sync

With Auto-Sync enabled:

```yaml
syncPolicy:
  automated: {}
```

Argo CD automatically detects Git changes and synchronizes them to Kubernetes.

Without Auto-Sync:

```text
Git Change
   ↓
Argo CD detects
   ↓
Manual Sync required
```

## 6. Important Commands

```bash
argocd app list
argocd app get my-app
argocd app sync my-app
argocd app delete my-app
```

### Interview Point

> An Argo CD Application defines the source repository, revision, path, destination cluster, namespace, and synchronization policy for deploying an application to Kubernetes.
