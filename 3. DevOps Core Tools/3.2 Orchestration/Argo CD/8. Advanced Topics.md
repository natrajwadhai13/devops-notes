# 8. Advanced Topics

## 1. Kustomize

* Kubernetes configuration management tool.
* Allows customization of common YAML files without duplicating them.
* Commonly used for **Dev / QA / Prod** environments.

```text
base/
overlays/
├── dev/
├── qa/
└── prod/
```

Argo CD can directly deploy Kustomize configurations.

---

## 2. ApplicationSet

* Used to create and manage **multiple Argo CD Applications automatically**.
* Useful for multiple environments, clusters, or applications.

```text
ApplicationSet
      ↓
 ┌────┼────┐
 ↓    ↓    ↓
Dev   QA   Prod
```

---

## 3. App of Apps

* One Argo CD Application manages other Argo CD Applications.
* Useful when you have many applications.

```text
        Root App
       /   |   \
      ↓    ↓    ↓
    App1  App2  App3
```

---

## 4. Multi-Environment Deployment

Manage different environments using Git:

```text
Git
├── dev
├── qa
└── prod
```

Each environment can have different:

* Replicas
* Image versions
* Configuration
* Resources

---

## 5. Multi-Cluster Deployment

Argo CD can manage applications across multiple Kubernetes clusters.

```text
             Argo CD
           /    |    \
          ↓     ↓     ↓
       Cluster1 Cluster2 Cluster3
```

---

## 6. RBAC

**Role-Based Access Control** controls what users can do in Argo CD.

Example:

* Developer → View/Sync applications
* Admin → Full access
* Read-only user → View only

---

## 7. Notifications

Argo CD can send notifications when application status changes.

Examples:

```text
Sync Failed
Application Degraded
Deployment Successful
```

Notifications can be integrated with tools such as Slack or email.

---

### Interview Priority

For your DevOps interview preparation, learn in this order:

**Kustomize → ApplicationSet → App of Apps → Multi-Cluster → RBAC → Notifications**

> **Most important:** ApplicationSet and Kustomize. App of Apps is also commonly asked in Argo CD interviews.
