# Argo CD Fundamentals

## 1. What is Argo CD?

* **Argo CD** is a **Kubernetes Continuous Delivery (CD) tool**.
* It follows the **GitOps** approach.
* Git repository is treated as the **single source of truth**.
* Argo CD continuously compares Git configuration with the Kubernetes cluster.

## 2. GitOps

**Git → Argo CD → Kubernetes**

* Developer changes Kubernetes configuration in Git.
* Argo CD detects the change.
* Argo CD synchronizes the change to Kubernetes.
* Kubernetes runs the desired configuration.

## 3. Key Features

* Automated deployment
* Git-based deployment
* Automatic synchronization
* Drift detection
* Self-healing
* Rollback to previous versions
* Web UI and CLI
* Supports Helm and Kustomize

## 4. Important Terms

| Term              | Meaning                                          |
| ----------------- | ------------------------------------------------ |
| **Application**   | Defines what should be deployed                  |
| **Repository**    | Git location containing Kubernetes configuration |
| **Sync**          | Applies Git configuration to Kubernetes          |
| **Refresh**       | Checks Git and cluster status                    |
| **Desired State** | Configuration stored in Git                      |
| **Live State**    | Current state in Kubernetes                      |
| **Drift**         | Difference between desired and live state        |
| **Healthy**       | Application is running correctly                 |
| **OutOfSync**     | Kubernetes state differs from Git                |

## 5. Basic Architecture

```text
GitHub / GitLab
      |
      v
   Argo CD
      |
      v
Kubernetes Cluster
      |
      v
   Application
```

### Important Point

**Argo CD does not replace Kubernetes.**
It manages and deploys applications **to Kubernetes** using GitOps.

**Interview Definition:**

> Argo CD is a Kubernetes-native GitOps continuous delivery tool that continuously monitors the desired state stored in Git and synchronizes it with the live state of the Kubernetes cluster.
