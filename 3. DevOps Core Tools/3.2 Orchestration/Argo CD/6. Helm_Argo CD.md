# 6. Helm + Argo CD

## 1. What is Helm?

* **Helm** is a package manager for Kubernetes.
* Helm uses **Charts** to define Kubernetes resources.
* `values.yaml` is used to customize deployments.

Example:

```text
Helm Chart
├── Chart.yaml
├── values.yaml
└── templates/
    ├── deployment.yaml
    └── service.yaml
```

## 2. Helm with Argo CD

Argo CD can deploy a Helm chart directly from Git.

```text
GitHub / GitLab
      |
      | Helm Chart
      v
   Argo CD
      |
      v
 Kubernetes
```

## 3. Important Helm Concepts

| Term            | Meaning                                 |
| --------------- | --------------------------------------- |
| **Chart**       | Package containing Kubernetes resources |
| **values.yaml** | Configuration/customization             |
| **templates**   | Kubernetes YAML templates               |
| **Chart.yaml**  | Chart metadata                          |
| **Release**     | Deployed instance of a chart            |

## 4. Environment Management

Different values can be maintained for different environments:

```text
Git
├── dev-values.yaml
├── qa-values.yaml
└── prod-values.yaml
```

Example:

```text
Dev  → 2 replicas
QA   → 3 replicas
Prod → 5 replicas
```

Argo CD can use the appropriate Helm values for each environment.

## 5. Why Helm + Argo CD?

* Helm → **Package and template Kubernetes applications**
* Argo CD → **Deploy and continuously synchronize them**
* Git → **Source of truth**

### Interview Point

> Helm packages and templates Kubernetes applications, while Argo CD manages their GitOps-based deployment and synchronization to Kubernetes.
