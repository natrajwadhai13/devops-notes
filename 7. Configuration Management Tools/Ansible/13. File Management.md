# 15. File Management Modules

## Learning Objectives

After completing this chapter, you will be able to:

- Manage files and directories.
- Copy files to managed nodes.
- Deploy Jinja2 templates.
- Retrieve files from managed nodes.
- Check file information.
- Create and extract archives.
- Modify configuration files.
- Synchronize files between servers.
- Understand the differences between file management modules.

---

# What are File Management Modules?

File Management Modules help manage files and directories on managed nodes.

Common tasks include:

- Copy files
- Create directories
- Delete files
- Modify configuration files
- Download log files
- Create backups
- Deploy templates

---

# Common File Management Modules

| Module | Purpose |
|---------|---------|
| copy | Copy files |
| template | Deploy Jinja2 templates |
| fetch | Copy files from managed nodes |
| file | Manage files/directories |
| stat | Get file information |
| archive | Create archives |
| unarchive | Extract archives |
| lineinfile | Modify one line |
| blockinfile | Add or remove blocks of text |
| replace | Replace text |
| assemble | Merge multiple files |
| synchronize | Sync files using rsync |

---

# Copy Module

Copies files from the Control Node to Managed Nodes.

```yaml
- name: Copy Configuration

  copy:

    src: app.conf

    dest: /etc/app.conf

    owner: root

    group: root

    mode: "0644"
```

Common Parameters

- src
- dest
- owner
- group
- mode
- backup
- force

---

# Template Module

Deploy dynamic configuration files.

```yaml
- name: Deploy Nginx Configuration

  template:

    src: nginx.conf.j2

    dest: /etc/nginx/nginx.conf
```

Used for

- nginx.conf
- httpd.conf
- haproxy.cfg
- application.properties

---

# Copy vs Template

| copy | template |
|------|----------|
| Static file | Dynamic file |
| No variables | Supports Jinja2 |
| Exact copy | Variable substitution |
| No logic | Supports loops and conditions |

---

# Fetch Module

Copies files **from Managed Nodes to the Control Node**.

```yaml
- name: Download Log File

  fetch:

    src: /var/log/messages

    dest: backup/

    flat: yes
```

Common Use Cases

- Log collection
- Configuration backup
- Database backups

---

# File Module

Manages files and directories.

Create Directory

```yaml
- file:

    path: /backup

    state: directory
```

Create Empty File

```yaml
- file:

    path: /tmp/demo.txt

    state: touch
```

Delete File

```yaml
- file:

    path: /tmp/demo.txt

    state: absent
```

Change Permissions

```yaml
- file:

    path: /opt/app

    owner: root

    group: root

    mode: "0755"
```

---

# Stat Module

Collect file information.

```yaml
- stat:

    path: /etc/passwd

  register: file_info
```

Display Output

```yaml
- debug:

    var: file_info.stat.exists
```

Useful Information

- Exists
- Owner
- Size
- Permissions
- File Type
- Last Modified

---

# Archive Module

Create compressed archives.

```yaml
- archive:

    path: /opt/project

    dest: /backup/project.tar.gz
```

Useful for backups.

---

# Unarchive Module

Extract archives.

```yaml
- unarchive:

    src: backup.tar.gz

    dest: /opt/

    remote_src: yes
```

---

# lineinfile Module

Modify a single line in a file.

Example

```yaml
- lineinfile:

    path: /etc/hosts

    line: "192.168.1.20 app01"
```

Replace Existing Line

```yaml
- lineinfile:

    path: /etc/ssh/sshd_config

    regexp: "^PermitRootLogin"

    line: "PermitRootLogin no"
```

---

# blockinfile Module

Insert multiple lines.

```yaml
- blockinfile:

    path: /etc/hosts

    block: |

      192.168.1.20 app01

      192.168.1.21 app02
```

Useful for

- SSH Config
- Hosts File
- Firewall Rules

---

# Replace Module

Replace matching text.

```yaml
- replace:

    path: /etc/httpd/conf/httpd.conf

    regexp: "80"

    replace: "8080"
```

---

# Assemble Module

Merge multiple files into one.

Directory

```
configs/

    app.conf

    db.conf

    ssl.conf
```

Playbook

```yaml
- assemble:

    src: configs/

    dest: /etc/application.conf
```

---

# Synchronize Module

Synchronize directories using **rsync**.

```yaml
- synchronize:

    src: backup/

    dest: /opt/backup/
```

Useful for

- Backups
- File Synchronization
- Large File Transfers

# Best Practices

- Use **copy** for static files.
- Use **template** for dynamic configuration files.
- Use **lineinfile** for small configuration changes.
- Use **blockinfile** for multiple lines.
- Use **fetch** to retrieve logs and backups.
- Use **stat** before modifying critical files.
- Use **backup: yes** before editing configuration files.
