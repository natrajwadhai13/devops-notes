# What is Azure Automation?

Azure Automation means using **Ansible** to create, configure, update, and delete Azure resources automatically.

Instead of manually using the Azure Portal or Azure CLI, Ansible communicates with Azure Resource Manager (ARM) APIs to manage cloud resources.

# Best Practices

* Use Managed Identity whenever possible.
* Store credentials in Ansible Vault.
* Organize automation using Roles.
* Tag Azure resources consistently.
* Test Playbooks in a non-production subscription.
* Keep Azure Collections updated.
* Use Resource Groups to organize infrastructure.

---

# Summary

* Ansible automates Azure using the `azure.azcollection` Collection.
* Authentication can be done using Azure CLI, Service Principals, or Managed Identities.
* Common automation targets include VMs, Networking, Storage, Databases, Containers, AKS, Monitoring, Backup, and Security services.
* Azure Automation enables consistent, repeatable, and scalable cloud infrastructure management.
