# Best Practices

- Never commit plain-text secrets to Git.
- Use Vault IDs for multiple environments.
- Rotate Vault passwords regularly.
- Store Vault password files securely.
- Encrypt only sensitive data.
- Use separate Vault files for Dev, Test, and Production.
