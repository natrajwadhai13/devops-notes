# Prerequisites

Before installing Ansible, make sure your system has:

- Python 3
- Internet connection
- Root or sudo access

> **Important:** Python must be installed on both the **Control Node** and **Managed Nodes** because Ansible modules run using Python.

---

# Check Python Version

Check whether Python is installed.

```bash
python3 --version
```

Example Output

```text
Python 3.12.3
```

---

# Check Python Location

```bash
which python3
```

Example Output

```text
/usr/bin/python3
```

---

# Install pip (RHEL / Rocky / AlmaLinux)

```bash
sudo dnf install python3-pip -y
```

---

# Install pipx

```bash
python3 -m pip install --user pipx
python3 -m pipx ensurepath
```

Verify pipx

```bash
pipx --version
```

---

# Install Ansible

Install the latest Ansible version.

```bash
pipx install --include-deps ansible
```

---

# Verify Installation

Check the installed version.

```bash
ansible --version
```

Example Output

```text
ansible [core 2.21.2]
```

---

# Understanding `ansible --version`

Run:

```bash
ansible --version
```

Example Output

```text
ansible [core 2.21.2]

config file = None

python version = 3.12.13

jinja version = 3.1.6

pyyaml version = 6.0.3
```

Explanation:

| Field | Description |
|---------|------------|
| ansible core | Installed Ansible version |
| config file | Configuration file being used |
| python version | Python version used by Ansible |
| jinja version | Template engine version |
| pyyaml version | YAML parser version |

---

# Ansible Configuration File

Sometimes the output shows:

```text
config file = None
```

This means Ansible is using the default settings because no configuration file has been created yet.

Later, you can create an `ansible.cfg` file to customize Ansible settings.

# Interview Questions

### Why does Ansible require Python?

Ansible modules execute on the managed node using Python. Therefore, Python must be installed on both the Control Node and Managed Nodes.

---

### Why use pipx instead of pip?

- Installs Ansible in an isolated environment.
- Prevents dependency conflicts.
- Easier to upgrade or remove.
- Recommended by the Ansible community.

---

### How do you verify Ansible installation?

```bash
ansible --version
```
