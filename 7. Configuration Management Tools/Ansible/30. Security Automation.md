# What is Security Automation?

Security Automation means using Ansible to automate security-related tasks instead of performing them manually.

Examples:

* Create users
* Disable root login
* Configure SSH
* Apply security patches
* Configure firewalls
* Audit systems
* Enforce security policies

# User Management

User accounts should be managed automatically.

Common Tasks

* Create Users
* Delete Users
* Lock Users
* Unlock Users
* Reset Passwords
* Add Users to Groups
* Remove Users from Groups

Example

```yaml
- name: Create User

  user:

    name: devops

    state: present
```

---

# SSH Hardening

SSH is commonly used to manage Linux servers.

Ansible can automate secure SSH configuration.

Common Tasks

* Disable Root Login
* Disable Password Authentication
* Allow SSH Key Authentication
* Change SSH Port
* Configure SSH Banner
* Restart SSH Service

Example

```yaml
- name: Disable Root Login

  lineinfile:

    path: /etc/ssh/sshd_config

    regexp: "^PermitRootLogin"

    line: "PermitRootLogin no"
```

---

# Firewall Automation

Firewalls control incoming and outgoing network traffic.

Ansible can automate firewall configuration.

Common Tasks

* Open Port
* Close Port
* Allow Service
* Remove Rules
* Reload Firewall

Common Firewall Modules

* firewalld
* ufw

Example

```yaml
- name: Allow HTTP

  firewalld:

    service: http

    permanent: true

    state: enabled
```

---

# SELinux

SELinux provides an additional layer of security on Linux systems.

Common Tasks

* Check SELinux Status
* Enable SELinux
* Disable SELinux
* Change Enforcement Mode
* Manage SELinux Booleans

Common Modes

* Enforcing
* Permissive
* Disabled

Example

```yaml
- name: Set SELinux Mode

  selinux:

    policy: targeted

    state: enforcing
```

# Patching

Keeping systems updated is essential for security.

Common Tasks

* Install Updates
* Upgrade Packages
* Security Updates
* Reboot After Updates

Example

```yaml
- name: Update Packages

  package:

    name: "*"

    state: latest
```

# Best Practices

* Use SSH Keys instead of passwords.
* Disable direct root login.
* Apply security patches regularly.
* Enable firewalls on all servers.
* Use SELinux in **Enforcing** mode where supported.
* Automate compliance checks.
* Follow the Principle of Least Privilege.
* Test Playbooks before production deployment.
* Store sensitive data in **Ansible Vault**.
