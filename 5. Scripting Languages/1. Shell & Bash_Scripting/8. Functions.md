# Module 8: Functions

A **Function** is a reusable block of code that performs a specific task.

Instead of writing the same code multiple times, you can define it once and call it whenever needed.

## Advantages

* Code Reusability
* Easy Maintenance
* Better Readability
* Modular Programming
* Less Code Duplication

---

# Function Declaration

There are two common ways to declare a function.

## Method 1 (Recommended)

```bash
function_name() {
    commands
}
```

### Example

```bash
#!/bin/bash

greet() {
    echo "Welcome to Shell Scripting"
}

greet
```

**Output**

```text
Welcome to Shell Scripting
```

---

## Method 2

```bash
function function_name {
    commands
}
```

### Example

```bash
#!/bin/bash

function hello {
    echo "Hello Linux"
}

hello
```

---

# Calling a Function

Simply use the function name.

```bash
#!/bin/bash

welcome() {
    echo "Welcome User"
}

welcome
welcome
welcome
```

Output

```text
Welcome User
Welcome User
Welcome User
```

# Function with Multiple Commands

```bash
#!/bin/bash

system_info() {

    echo "User      : $(whoami)"
    echo "Hostname  : $(hostname)"
    echo "Date      : $(date)"
    echo "Directory : $(pwd)"

}

system_info
```

# Return Values

Functions return an **Exit Status**, not a string.

The `return` command can return numbers from **0 to 255**.

## Syntax

```bash
return number
```

---

## Example

```bash
#!/bin/bash

check() {

    return 0

}

check

echo $?
```

Output

```text
0
```

---

## Example

```bash
#!/bin/bash

validate() {

    return 1

}

validate

echo $?
```

Output

```text
1
```

---

## Return Success / Failure

```bash
#!/bin/bash

check_file() {

    if [ -f "/etc/passwd" ]
    then
        return 0
    else
        return 1
    fi

}

check_file

if [ $? -eq 0 ]
then
    echo "File Exists"
else
    echo "File Not Found"
fi
```

# Returning Text from a Function

Functions cannot directly return strings using `return`.

Instead, print the value and capture it using **Command Substitution**.

```bash
#!/bin/bash

get_name() {

    echo "Natraj"

}

name=$(get_name)

echo "$name"
```

Output

```text
Natraj
```

# Local Variables

Variables inside a function are **Global by default**.

Use `local` to limit the variable to the function.

---

## Without local

```bash
#!/bin/bash

name="Linux"

demo() {

    name="Docker"

}

demo

echo "$name"
```

Output

```text
Docker
```

The global variable changed.

---

## With local

```bash
#!/bin/bash

name="Linux"

demo() {

    local name="Docker"

    echo "$name"

}

demo

echo "$name"
```

Output

```text
Docker
Linux
```

The global variable remains unchanged.

# Passing Arguments

Functions can accept arguments just like shell scripts.

Inside a function:

* `$1` → First Argument
* `$2` → Second Argument
* `$3` → Third Argument

---

## Example

```bash
#!/bin/bash

greet() {

    echo "Hello $1"

}

greet Natraj
```

Output

```text
Hello Natraj
```

---

## Multiple Arguments

```bash
#!/bin/bash

employee() {

    echo "Name    : $1"
    echo "Company : $2"
    echo "Salary  : $3"

}

employee Natraj Infosys 1100000
```

Output

```text
Name    : Natraj
Company : Infosys
Salary  : 1100000
```

---

# All Function Arguments

```bash
#!/bin/bash

show() {

    echo "Arguments : $@"
    echo "Total     : $#"

}

show Linux Docker Kubernetes
```

Output

```text
Arguments : Linux Docker Kubernetes
Total     : 3
```

# Recursive Functions

A **Recursive Function** is a function that calls itself.

Use recursion carefully because excessive recursion can cause a stack overflow.

---

## Example (Countdown)

```bash
#!/bin/bash

countdown() {

    if [ $1 -eq 0 ]
    then
        return
    fi

    echo "$1"

    countdown $(( $1 - 1 ))

}

countdown 5
```

Output

```text
5
4
3
2
1
```

---

## Example (Factorial)

```bash
#!/bin/bash

factorial() {

    if [ $1 -le 1 ]
    then
        echo 1
    else
        local result=$(factorial $(( $1 - 1 )))
        echo $(( $1 * result ))
    fi

}

factorial 5
```

Output

```text
120
```

# Complete Example

```bash
#!/bin/bash

greet() {

    echo "Hello $1"

}

addition() {

    local sum=$(( $1 + $2 ))

    echo "$sum"

}

greet Natraj

result=$(addition 20 30)

echo "Total : $result"
```

Output

```text
Hello Natraj
Total : 50
```

# Quick Summary

| Topic              | Description                     |
| ------------------ | ------------------------------- |
| Function           | Reusable block of code          |
| Declaration        | `name(){}` or `function name{}` |
| Return Value       | `return 0-255`                  |
| Local Variable     | `local variable=value`          |
| Arguments          | `$1`, `$2`, `$3`                |
| Recursive Function | Function calling itself         |

---

# Best Practices

* Use meaningful function names (`backup_files`, `check_disk`, `restart_service`).
* Keep each function focused on one task.
* Use `local` for variables that are only needed inside the function.
* Return status codes (`0` for success, non-zero for failure).
* Use `echo` with command substitution (`result=$(function_name)`) when returning text or calculated values.
* Avoid deep recursion in Bash; loops are generally more efficient.

# Interview Questions

### 1. What is a function in Shell Scripting?

A function is a reusable block of code that performs a specific task and can be called multiple times.

### 2. How do you declare a function?

```bash
my_function() {
    commands
}
```

### 3. How do you call a function?

Use the function name:

```bash
my_function
```

### 4. What is the purpose of `local`?

It restricts a variable's scope to the current function, preventing changes to global variables.

### 5. Can a Bash function return a string?

No. The `return` statement can only return an exit status (0–255). To "return" text, print it with `echo` and capture it using command substitution:

```bash
result=$(my_function)
```

### 6. How are arguments passed to a function?

Using positional parameters (`$1`, `$2`, `$3`, ...).

### 7. What is a recursive function?

A function that calls itself until a stopping condition (base case) is reached.

### 8. What is the difference between `return` and `echo` in a function?

| `return`                         | `echo`                                    |
| -------------------------------- | ----------------------------------------- |
| Returns an exit status (0–255)   | Outputs text or values                    |
| Used to indicate success/failure | Used to produce data that can be captured |
