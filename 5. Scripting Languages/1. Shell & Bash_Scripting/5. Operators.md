# Module 5: Operators

Operators are symbols used to perform operations on variables and values.

There are five main types of operators in Bash:

1. Arithmetic Operators
2. Comparison Operators
3. String Operators
4. Logical Operators
5. File Test Operators

---

# 1. Arithmetic Operators

Arithmetic operators perform mathematical calculations.

> **Note:** Use `(( ))`, `let`, or `$(( ))` for arithmetic operations.

## Syntax

```bash
result=$((num1 + num2))
```

---

## Arithmetic Operators Table

| Operator | Description         | Example     |
| -------- | ------------------- | ----------- |
| `+`      | Addition            | `10 + 5`    |
| `-`      | Subtraction         | `10 - 5`    |
| `*`      | Multiplication      | `10 * 5`    |
| `/`      | Division            | `10 / 5`    |
| `%`      | Modulus (Remainder) | `10 % 3`    |
| `++`     | Increment           | `((num++))` |
| `--`     | Decrement           | `((num--))` |

---

## Example

```bash
#!/bin/bash

num1=20
num2=10

echo "Addition       : $((num1 + num2))"
echo "Subtraction    : $((num1 - num2))"
echo "Multiplication : $((num1 * num2))"
echo "Division       : $((num1 / num2))"
echo "Modulus        : $((num1 % num2))"
```

**Output**

```text
Addition       : 30
Subtraction    : 10
Multiplication : 200
Division       : 2
Modulus        : 0
```

---

# Increment & Decrement

```bash
#!/bin/bash

num=10

((num++))
echo $num

((num--))
echo $num
```

Output

```text
11
10
```

# 2. Comparison Operators

Comparison operators compare numbers.

They are commonly used with `if` conditions.

---

## Numeric Comparison Operators

| Operator | Meaning               |
| -------- | --------------------- |
| `-eq`    | Equal                 |
| `-ne`    | Not Equal             |
| `-gt`    | Greater Than          |
| `-lt`    | Less Than             |
| `-ge`    | Greater Than or Equal |
| `-le`    | Less Than or Equal    |

---

## Example

```bash
#!/bin/bash

num1=20
num2=10

if [ $num1 -gt $num2 ]
then
    echo "num1 is Greater"
fi
```

Output

```text
num1 is Greater
```

---

## More Examples

```bash
[ 10 -eq 10 ]   # Equal

[ 10 -ne 5 ]    # Not Equal

[ 20 -gt 10 ]   # Greater

[ 10 -lt 20 ]   # Less

[ 10 -ge 10 ]   # Greater or Equal

[ 10 -le 20 ]   # Less or Equal
```

# 3. String Operators

String operators compare text values.

---

## String Operator Table

| Operator | Meaning             |
| -------- | ------------------- |
| `=`      | Equal               |
| `!=`     | Not Equal           |
| `-z`     | String is Empty     |
| `-n`     | String is Not Empty |

---

## Equal Example

```bash
#!/bin/bash

name="Linux"

if [ "$name" = "Linux" ]
then
    echo "Matched"
fi
```

Output

```text
Matched
```

---

## Not Equal

```bash
[ "$name" != "Windows" ]
```

---

## Empty String

```bash
name=""

if [ -z "$name" ]
then
    echo "Empty"
fi
```

Output

```text
Empty
```

---

## Not Empty

```bash
name="Natraj"

if [ -n "$name" ]
then
    echo "Not Empty"
fi
```

Output

```text
Not Empty
```

# 4. Logical Operators

Logical operators combine multiple conditions.

---

## Operator Table

| Operator | Meaning |
| -------- | ------- |
| `&&`     | AND     |
| `\|\|`   | OR      |
| `!`      | NOT     |

---

## AND Operator

Both conditions must be true.

```bash
#!/bin/bash

age=25

if [[ $age -ge 18 && $age -le 60 ]]
then
    echo "Eligible"
fi
```

Output

```text
Eligible
```

---

## OR Operator

Only one condition needs to be true.

```bash
#!/bin/bash

marks=35

if [[ $marks -ge 40 || $marks -eq 35 ]]
then
    echo "Pass"
fi
```

---

## NOT Operator

```bash
#!/bin/bash

name="Windows"

if [[ ! "$name" = "Linux" ]]
then
    echo "Not Linux"
fi
```

Output

```text
Not Linux
```

# 5. File Test Operators

File test operators check file and directory properties.

---

## File Test Operator Table

| Operator | Description               |
| -------- | ------------------------- |
| `-e`     | File or Directory Exists  |
| `-f`     | Regular File              |
| `-d`     | Directory                 |
| `-r`     | Read Permission           |
| `-w`     | Write Permission          |
| `-x`     | Execute Permission        |
| `-s`     | File Exists and Not Empty |
| `-L`     | Symbolic Link             |

---

## File Exists

```bash
#!/bin/bash

file="/etc/passwd"

if [ -e "$file" ]
then
    echo "File Exists"
fi
```

Output

```text
File Exists
```

---

## Directory Exists

```bash
dir="/home"

if [ -d "$dir" ]
then
    echo "Directory Found"
fi
```

---

## Regular File

```bash
if [ -f "/etc/passwd" ]
then
    echo "Regular File"
fi
```

---

## Read Permission

```bash
if [ -r "/etc/passwd" ]
then
    echo "Readable"
fi
```

---

## Write Permission

```bash
if [ -w "demo.txt" ]
then
    echo "Writable"
fi
```

---

## Execute Permission

```bash
if [ -x "backup.sh" ]
then
    echo "Executable"
fi
```

---

## File Not Empty

```bash
if [ -s "demo.txt" ]
then
    echo "File is Not Empty"
fi
```

---

## Symbolic Link

```bash
if [ -L "/usr/bin/python" ]
then
    echo "Symbolic Link"
fi
```

# Complete Example

```bash
#!/bin/bash

read -p "Enter First Number : " num1
read -p "Enter Second Number: " num2

echo "Addition : $((num1 + num2))"

if [ $num1 -gt $num2 ]
then
    echo "$num1 is Greater"
else
    echo "$num2 is Greater"
fi
```

# Best Practices

- Use **`(( ))`** or **`$(( ))`** for arithmetic operations.
- Quote string variables:

```bash
if [ "$name" = "Linux" ]
```

- Prefer **`[[ ]]`** when using logical operators (`&&`, `||`) because it is safer and more feature-rich than `[ ]`.
- Always quote file paths to handle spaces:

```bash
if [ -f "$file" ]
```

# Interview Questions

### 1. What are arithmetic operators in Bash?

Operators used for mathematical calculations, such as `+`, `-`, `*`, `/`, `%`, `++`, and `--`.

### 2. What is the difference between `-eq` and `=`?

- `-eq` compares **numeric values**.
- `=` compares **string values**.

### 3. What is the difference between `-z` and `-n`?

- `-z` checks whether a string is **empty**.
- `-n` checks whether a string is **not empty**.

### 4. What do `&&` and `||` mean?

- `&&` (AND): All conditions must be true.
- `||` (OR): At least one condition must be true.

### 5. What is the difference between `-f` and `-d`?

- `-f` checks for a **regular file**.
- `-d` checks for a **directory**.

### 6. Which operator checks if a file exists?

`-e`

### 7. Which operator checks execute permission?

`-x`

### 8. Which operator checks whether a file exists and is not empty?

`-s`
