# Module 15: Process Management

A **Process** is a running instance of a program.

Examples:

* Running `nginx`
* Executing a shell script
* Opening `vim`
* Running `docker`
* Executing `sleep 100`

Every process has a unique **PID (Process ID)** assigned by the Linux kernel.

---

# Process States

| State | Meaning                          |
| ----- | -------------------------------- |
| **R** | Running                          |
| **S** | Sleeping                         |
| **D** | Uninterruptible Sleep (Disk I/O) |
| **T** | Stopped                          |
| **Z** | Zombie                           |
| **X** | Dead (Rare)                      |

Check process state:

```bash id="q44p4d"
ps -el
```


---

## Common Signals

| Signal  | Number | Description                    |
| ------- | ------ | ------------------------------ |
| SIGTERM | 15     | Gracefully terminate (Default) |
| SIGKILL | 9      | Forcefully kill                |
| SIGSTOP | 19     | Pause process                  |
| SIGCONT | 18     | Resume process                 |
| SIGHUP  | 1      | Reload configuration           |

# 8. nohup

`nohup` (No Hang Up) keeps a process running even after logout.

Normally:

```bash id="5syvzd"
./backup.sh
```

If you log out, the script stops.

---

Using `nohup`

```bash id="33njm8"
nohup ./backup.sh &
```

Output

```text id="t5d6lz"
appending output to nohup.out
```

---

## Custom Log File

```bash id="g9j1w9"
nohup ./backup.sh > backup.log 2>&1 &
```

---

## Check Running

```bash id="yg0gvc"
ps -ef | grep backup.sh
```

# 9. nice

`nice` starts a process with a specified priority.

Lower nice value → Higher priority

Higher nice value → Lower priority

Range

```text id="vqehih"
-20 to 19
```

* `-20` → Highest Priority
* `19` → Lowest Priority

Default

```text id="3bjykw"
0
```

---

## Start Low Priority

```bash id="z2og1m"
nice -n 10 tar -czf backup.tar.gz /home
```

---

## View Nice Value

```bash id="8wnzha"
ps -el
```

or

```bash id="lyegdk"
top
```

Look at the **NI** column.

---

## Change Priority of Running Process

Using `renice`

```bash id="i86dt6"
renice 10 -p 2456
```

# Background vs Foreground

| Foreground           | Background                |
| -------------------- | ------------------------- |
| User waits           | User can continue working |
| Attached to terminal | Runs independently        |
| One active command   | Multiple background jobs  |

# Common Signals

| Signal | Command        | Purpose              |
| ------ | -------------- | -------------------- |
| 1      | `kill -1 PID`  | Reload configuration |
| 2      | Ctrl + C       | Interrupt process    |
| 9      | `kill -9 PID`  | Force kill           |
| 15     | `kill PID`     | Graceful termination |
| 18     | `kill -18 PID` | Continue process     |
| 19     | `kill -19 PID` | Stop process         |

# Best Practices

* Use `kill` (SIGTERM) before `kill -9` to allow graceful shutdown.
* Use `ps -ef | grep process_name` to locate a process before terminating it.
* Use `nohup` for long-running scripts that must survive logout.
* Run CPU-intensive background jobs with `nice` to reduce their impact on the system.
* Verify the PID before issuing `kill` or `kill -9`.
* Use `jobs`, `bg`, and `fg` only for processes started from the current shell session.

# Interview Questions

### 1. What is a process?

A process is a running instance of a program, identified by a unique Process ID (PID).

---

### 2. What is the difference between `ps` and `top`?

| `ps`                  | `top`                         |
| --------------------- | ----------------------------- |
| Snapshot of processes | Real-time process monitoring  |
| Static output         | Continuously updating display |

---

### 3. What is the difference between `kill` and `killall`?

* `kill` terminates a process using its **PID**.
* `killall` terminates one or more processes using the **process name**.

---

### 4. What is the difference between `kill` and `kill -9`?

* `kill` sends **SIGTERM (15)**, allowing the process to shut down gracefully.
* `kill -9` sends **SIGKILL (9)**, immediately terminating the process without cleanup.

---

### 5. What is the purpose of `nohup`?

It allows a process to continue running even after the user logs out or the terminal session ends.

---

### 6. What is the purpose of `nice`?

It starts a process with a specified CPU scheduling priority (nice value).

---

### 7. What is the difference between `bg` and `fg`?

* `bg` resumes a stopped job in the background.
* `fg` brings a background or stopped job to the foreground.

---

### 8. How do you check background jobs?

```bash id="s9s2vj"
jobs
```

---

### 9. Which signal is used for graceful termination?

**SIGTERM (15)**

---

### 10. Which signal forcefully terminates a process?

**SIGKILL (9)**
