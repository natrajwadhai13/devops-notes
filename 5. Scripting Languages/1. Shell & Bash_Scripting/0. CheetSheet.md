# 34. Safe Script Template

```bash
#!/bin/bash

set -euo pipefail

LOG_FILE="/tmp/script.log"

log() {
    echo "$(date) : $1" | tee -a "$LOG_FILE"
}

main() {

    log "Script Started"

    # Code Here

    log "Completed"

}

main
```

nohup ./script.sh &

# 38. Production Script Checklist ✅

- ✅ `#!/bin/bash`
- ✅ `set -euo pipefail`
- ✅ Use meaningful variable names
- ✅ Quote variables (`"$var"`)
- ✅ Validate user input
- ✅ Handle errors
- ✅ Use functions
- ✅ Add logging
- ✅ Use `trap` for cleanup
- ✅ Test before production
- ✅ Use absolute paths
- ✅ Check command exit status
- ✅ Avoid hardcoded passwords
- ✅ Add comments where necessary
