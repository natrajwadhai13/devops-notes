# Module 7: Loops

Loops are used to execute the same block of code **multiple times** until a condition is met.

They help automate repetitive tasks like:

* Creating users
* Checking services
* Processing log files
* Reading files
* Taking backups
* Monitoring servers

---

# Types of Loops

| Loop          | Purpose                                                  |
| ------------- | -------------------------------------------------------- |
| `for`         | Repeat a fixed number of times or iterate through a list |
| `while`       | Run while a condition is true                            |
| `until`       | Run until a condition becomes true                       |
| Infinite Loop | Runs forever until stopped                               |

---

# 1. for Loop

The `for` loop is used when you know how many times the loop should execute.

---

## Syntax 1 (List)

```bash
for variable in list
do
    commands
done
```

---

## Example 1

```bash
#!/bin/bash

for name in Linux Docker Kubernetes AWS
do
    echo "$name"
done
```

Output

```text
Linux
Docker
Kubernetes
AWS
```

---

## Syntax 2 (Range)

```bash
for variable in {1..5}
do
    commands
done
```

---

## Example 2

```bash
#!/bin/bash

for i in {1..5}
do
    echo "$i"
done
```

Output

```text
1
2
3
4
5
```

---

## Example 3 (C Style)

```bash
#!/bin/bash

for ((i=1;i<=5;i++))
do
    echo "$i"
done
```

Output

```text
1
2
3
4
5
```

---

## Example 4 (Even Numbers)

```bash
#!/bin/bash

for ((i=0;i<=10;i+=2))
do
    echo "$i"
done
```

Output

```text
0
2
4
6
8
10
```

---

# 2. while Loop

The `while` loop executes as long as the condition is **true**.

---

## Syntax

```bash
while [ condition ]
do
    commands
done
```

---

## Example

```bash
#!/bin/bash

num=1

while [ $num -le 5 ]
do
    echo "$num"
    ((num++))
done
```

Output

```text
1
2
3
4
5
```

---

## Example (User Input)

```bash
#!/bin/bash

read -p "Enter Number: " num

while [ $num -gt 0 ]
do
    echo "$num"
    ((num--))
done
```

---

# 3. until Loop

The `until` loop runs until the condition becomes **true**.

It is the opposite of a `while` loop.

---

## Syntax

```bash
until [ condition ]
do
    commands
done
```

---

## Example

```bash
#!/bin/bash

num=1

until [ $num -gt 5 ]
do
    echo "$num"
    ((num++))
done
```

Output

```text
1
2
3
4
5
```

---

## Difference: while vs until

| while                              | until                             |
| ---------------------------------- | --------------------------------- |
| Runs while condition is true       | Runs while condition is false     |
| Stops when condition becomes false | Stops when condition becomes true |

Example

```bash
while [ $num -le 5 ]
```

means

> Continue while `num <= 5`

---

```bash
until [ $num -gt 5 ]
```

means

> Continue until `num > 5`

---

# 4. Infinite Loop

An infinite loop runs continuously until manually stopped.

Stop it using:

```text
Ctrl + C
```

---

## Method 1

```bash
#!/bin/bash

while true
do
    echo "Running..."
    sleep 2
done
```

---

## Method 2

```bash
#!/bin/bash

while :
do
    echo "Running..."
done
```

---

## Method 3

```bash
#!/bin/bash

for (( ; ; ))
do
    echo "Running..."
done
```

---

# 5. break Statement

`break` immediately exits the loop.

---

## Example

```bash
#!/bin/bash

for i in {1..10}
do

    if [ $i -eq 5 ]
    then
        break
    fi

    echo "$i"

done
```

Output

```text
1
2
3
4
```

Loop stops when `i` becomes `5`.

---

## Example (while)

```bash
#!/bin/bash

num=1

while true
do

    echo "$num"

    if [ $num -eq 5 ]
    then
        break
    fi

    ((num++))

done
```

---

# 6. continue Statement

`continue` skips the current iteration and moves to the next iteration.

---

## Example

```bash
#!/bin/bash

for i in {1..5}
do

    if [ $i -eq 3 ]
    then
        continue
    fi

    echo "$i"

done
```

Output

```text
1
2
4
5
```

Number `3` is skipped.

---

## Example (Even Numbers)

```bash
#!/bin/bash

for ((i=1;i<=10;i++))
do

    if (( i % 2 != 0 ))
    then
        continue
    fi

    echo "$i"

done
```

Output

```text
2
4
6
8
10
```

---

# Nested Loop

A loop inside another loop.

```bash
#!/bin/bash

for i in {1..3}
do

    for j in {1..2}
    do
        echo "$i $j"
    done

done
```

Output

```text
1 1
1 2
2 1
2 2
3 1
3 2
```

```bash
#!/bin/bash

for ((i=1;i<=10;i++))
do

    if (( i % 2 == 0 ))
    then
        echo "$i"
    fi

done
```

Output

```text

4
```

# Quick Summary

| Loop          | Purpose                               |
| ------------- | ------------------------------------- |
| `for`         | Fixed iterations or lists             |
| `while`       | Executes while condition is true      |
| `until`       | Executes until condition becomes true |
| Infinite Loop | Never ends until stopped              |
| `break`       | Exit loop immediately                 |
| `continue`    | Skip current iteration                |

---

# Best Practices

* Use **`for`** when the number of iterations is known.
* Use **`while`** for condition-based loops.
* Use **`until`** when it is easier to express the stopping condition.
* Avoid infinite loops unless required (e.g., monitoring scripts).
* Use `sleep` inside infinite loops to reduce CPU usage.
* Use `break` to exit early when a condition is met.
* Use `continue` to skip unwanted iterations.

# Real-World DevOps Examples

### Check Disk Usage Every 10 Seconds

```bash
while true
do
    df -h
    sleep 10
done
```

---

### Ping a Server 5 Times

```bash
for ((i=1;i<=5;i++))
do
    ping -c 1 google.com
done
```

---

### Read Log File Line by Line

```bash
while read line
do
    echo "$line"
done < /var/log/messages
```

---

### Create Multiple Users

```bash
for user in user1 user2 user3
do
    useradd "$user"
done
```

# Interview Questions

### 1. What is a loop in Shell Scripting?

A loop repeatedly executes a block of code until a specified condition is met.

### 2. What is the difference between `for` and `while`?

* `for` is used when the number of iterations is known.
* `while` is used when execution depends on a condition.

### 3. What is the difference between `while` and `until`?

* `while` runs while the condition is **true**.
* `until` runs while the condition is **false** and stops when it becomes true.

### 4. What does the `break` statement do?

It immediately exits the current loop.

### 5. What does the `continue` statement do?

It skips the rest of the current iteration and proceeds with the next iteration.

### 6. How do you create an infinite loop?

```bash
while true
do
    # commands
done
```

or

```bash
while :
do
    # commands
done
```

### 7. Why is `sleep` often used in infinite loops?

To prevent high CPU usage by pausing execution between iterations.
