# Module 4: User Input

User input allows a shell script to accept values from the keyboard during execution.

The **`read`** command is used to take input from the user.

---

# read Command

The `read` command reads input from the keyboard and stores it in a variable.

### Syntax

```bash
read variable_name
```

### Example

```bash
#!/bin/bash

echo "Enter Your Name:"
read name

echo "Welcome $name"
```

**Output**

```text
Enter Your Name:
Natraj

Welcome Natraj
```

---

# Prompt Message

Instead of using `echo`, you can display the prompt directly using the `-p` option.

### Syntax

```bash
read -p "Message: " variable
```

### Example

```bash
#!/bin/bash

read -p "Enter Your Name: " name

echo "Hello $name"
```

**Output**

```text
Enter Your Name: Natraj

Hello Natraj
```

---

# Hidden Password (`read -s`)

The `-s` (silent) option hides the characters while typing.

It is mainly used for passwords.

### Example

```bash
#!/bin/bash

read -s -p "Enter Password: " password

echo
echo "Password Saved Successfully"
```

**Output**

```text
Enter Password:
Password Saved Successfully
```

> **Note:** Nothing is displayed while typing the password.

---

# Multiple Inputs

You can read multiple values in a single command.

### Syntax

```bash
read var1 var2 var3
```

### Example

```bash
#!/bin/bash

read -p "Enter Name Age City: " name age city

echo "Name : $name"
echo "Age  : $age"
echo "City : $city"
```

**Output**

```text
Enter Name Age City:
Natraj 32 Pune

Name : Natraj
Age  : 32
City : Pune
```

---

# Default Values

Bash does not have a built-in default value option in `read`, but it can be implemented using parameter expansion.

### Method 1: Press Enter to Use Default

```bash
#!/bin/bash

read -p "Enter Your Name [Guest]: " name

name=${name:-Guest}

echo "Welcome $name"
```

### Output 1

```text
Enter Your Name [Guest]:
Welcome Guest
```

### Output 2

```text
Enter Your Name [Guest]: Natraj

Welcome Natraj
```

---

## Method 2: Default Value for Numbers

```bash
#!/bin/bash

read -p "Enter Port Number [8080]: " port

port=${port:-8080}

echo "Port : $port"
```

---

# Read Input into an Array

Use `-a` to store multiple values in an array.

```bash
#!/bin/bash

read -p "Enter Three Subjects: " -a subjects

echo "Subject 1 : ${subjects[0]}"
echo "Subject 2 : ${subjects[1]}"
echo "Subject 3 : ${subjects[2]}"
```

**Output**

```text
Enter Three Subjects:
Linux Docker Kubernetes

Subject 1 : Linux
Subject 2 : Docker
Subject 3 : Kubernetes
```

---

# Read Without Variable

If no variable is provided, input is stored in the special variable **`REPLY`**.

```bash
#!/bin/bash

read -p "Enter Your Name: "

echo "Hello $REPLY"
```

---

# Read with Time Limit

The `-t` option sets a timeout.

```bash
#!/bin/bash

read -t 5 -p "Enter Your Name (within 5 sec): " name

echo
echo "Name : $name"
```

If the user doesn't respond within 5 seconds, `read` exits.

---

# Read Limited Characters

The `-n` option limits the number of characters read.

```bash
#!/bin/bash

read -n 1 -p "Continue (Y/N): " choice

echo
echo "You Selected : $choice"
```

**Output**

```text
Continue (Y/N): Y

You Selected : Y
```

---

# Common `read` Options

| Option | Description                                |
| ------ | ------------------------------------------ |
| `-p`   | Display prompt message                     |
| `-s`   | Hide input (silent mode)                   |
| `-a`   | Store input in an array                    |
| `-t`   | Timeout in seconds                         |
| `-n`   | Read fixed number of characters            |
| `-r`   | Read raw input (don't treat `\` as escape) |

---

# Complete Example

```bash
#!/bin/bash

echo "========== User Registration =========="

read -p "Enter Name: " name

read -p "Enter Age: " age

read -p "Enter City: " city

read -s -p "Enter Password: " password

echo

echo "========== Details =========="
echo "Name : $name"
echo "Age  : $age"
echo "City : $city"
echo "Registration Successful!"
```

**Output**

```text
========== User Registration ==========

Enter Name: Natraj
Enter Age: 32
Enter City: Pune
Enter Password:

========== Details ==========
Name : Natraj
Age  : 32
City : Pune
Registration Successful!
```

---

# Best Practices

- Use `read -p` instead of a separate `echo` for cleaner scripts.
- Use `read -s` for passwords or sensitive input.
- Quote variables when displaying them:

```bash
echo "$name"
```

- Provide sensible default values for optional inputs.
- Validate user input before using it in critical operations.

# Interview Questions

### 1. What is the purpose of the `read` command?

It reads input from the user and stores it in one or more variables.

### 2. What does `read -p` do?

It displays a prompt message and waits for user input.

### 3. What is the use of `read -s`?

It hides the typed characters, commonly used for password input.

### 4. How do you read multiple values in one command?

```bash
read name age city
```

### 5. How do you provide a default value if the user presses Enter?

```bash
name=${name:-Guest}
```

### 6. Which special variable stores input when no variable name is provided?

`REPLY`

### 7. What does `read -t` do?

It waits for input for a specified number of seconds before timing out.

### 8. What does `read -n 1` do?

It reads only one character from the user without requiring the Enter key after additional characters.
