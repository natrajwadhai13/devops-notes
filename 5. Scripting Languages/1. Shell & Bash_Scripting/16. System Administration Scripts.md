# Module 16: System Administration Scripts

System Administration Scripts automate daily Linux administration tasks.

These scripts are commonly used by:

* Linux Administrators
* DevOps Engineers
* Cloud Engineers
* Site Reliability Engineers (SRE)

Common tasks:

* User Management
* Password Management
* Group Management
* Resource Monitoring
* Service Monitoring
* Health Checks
* Reporting

---

# 1. User Creation

The `useradd` command creates a new Linux user.

## Create User

```bash
sudo useradd john
```

---

## Create User with Home Directory

```bash
sudo useradd -m john
```

---

## Set Password

```bash
sudo passwd john
```

---

## User Creation Script

```bash
#!/bin/bash

read -p "Enter Username: " username

if id "$username" &>/dev/null
then
    echo "User Already Exists"
else
    sudo useradd -m "$username"
    sudo passwd "$username"
    echo "User Created Successfully"
fi
```

# 3. User Deletion

Delete a Linux user.

---

## Delete User Only

```bash
sudo userdel john
```

---

## Delete User with Home Directory

```bash
sudo userdel -r john
```

---

## Script

```bash
#!/bin/bash

read -p "Enter Username: " username

if id "$username" &>/dev/null
then
    sudo userdel -r "$username"
    echo "User Deleted"
else
    echo "User Not Found"
fi
```

# 4. Group Management

Groups help manage permissions for multiple users.

---

## Create Group

```bash
sudo groupadd developers
```

---

## Delete Group

```bash
sudo groupdel developers
```

---

## Add User to Group

```bash
sudo usermod -aG developers john
```

---

## Remove User from Group

```bash
sudo gpasswd -d john developers
```

---

## Display User Groups

```bash
groups john
```

---

## Script

```bash
#!/bin/bash

read -p "Enter Username: " user

read -p "Enter Group Name: " group

sudo usermod -aG "$group" "$user"

echo "User Added to Group"
```

---

## Script

```bash

```

---

## Alert When Disk Usage Exceeds 80%

```bash
#!/bin/bash

THRESHOLD=80

df -hP | awk 'NR>1 {print $6,$5}' | while read mount usage
do

    usage=${usage%\%}

    if [ "$usage" -ge "$THRESHOLD" ]
    then
        echo "WARNING: $mount is ${usage}% full"
    fi

done
```

# 8. Service Status

Check whether a service is running.

---

## Check Status

```bash
systemctl status nginx
```

---

## Check Active

```bash
systemctl is-active nginx
```

Output

```text
active
```

---

## Script

```bash
#!/bin/bash

SERVICE="nginx"

if systemctl is-active --quiet "$SERVICE"
then
    echo "$SERVICE is Running"
else
    echo "$SERVICE is Stopped"
fi
```

---

## Restart Service if Down

```bash
#!/bin/bash

SERVICE="nginx"

if ! systemctl is-active --quiet "$SERVICE"
then

    echo "Restarting..."

    sudo systemctl restart "$SERVICE"

fi
```

# Best Practices

* Always check if a user or group exists before creating or deleting it.
* Quote variables to handle spaces safely:

```bash
useradd "$username"
```

* Use `systemctl is-active --quiet` in scripts instead of parsing `systemctl status`.
* Define thresholds (for example, disk usage at 80%) as variables so they are easy to change.
* Redirect health-check output to log files for auditing and troubleshooting.
* Test administration scripts in a non-production environment before running them on production servers.
