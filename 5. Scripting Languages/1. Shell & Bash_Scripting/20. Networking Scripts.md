# Module 20: Networking Scripts

Networking commands are essential for **Linux Administrators**, **DevOps Engineers**, **Cloud Engineers**, and **SREs**.

They are used to:

* Check network connectivity
* Connect to remote servers
* Transfer files
* Test APIs
* Verify open ports
* Troubleshoot network issues
* Monitor services

---

# Common Networking Commands

| Command       | Purpose                                |
| ------------- | -------------------------------------- |
| `ping`        | Check network connectivity             |
| `ssh`         | Remote login                           |
| `scp`         | Secure file transfer                   |
| `curl`        | Transfer data / Test APIs              |
| `wget`        | Download files                         |
| `netstat`     | Display network connections            |
| `ss`          | Modern replacement for netstat         |
| `nc` (Netcat) | Network troubleshooting & port testing |

---

# 1. ping

`ping` checks whether a remote host is reachable.

It uses the **ICMP** protocol.

---

## Syntax

```bash
ping hostname
```

---

## Example

```bash
ping google.com
```

Stop

```text
Ctrl + C
```

---

## Send 4 Packets

```bash
ping -c 4 google.com
```

---

## Ping IP Address

```bash
ping 8.8.8.8
```

---

## Script Example

```bash
#!/bin/bash

HOST="google.com"

if ping -c 2 "$HOST" > /dev/null
then
    echo "$HOST is Reachable"
else
    echo "$HOST is Unreachable"
fi
```

# 2. ssh

`ssh` (Secure Shell) connects securely to a remote Linux server.

Default Port

```text
22
```

---

## Connect to Server

```bash
ssh user@192.168.1.10
```

---

## Connect Using Port

```bash
ssh -p 2222 user@server
```

---

## Execute Remote Command

```bash
ssh user@server "hostname"
```

---

## SSH Key Login

```bash
ssh -i id_rsa user@server
```

---

## Script Example

```bash
#!/bin/bash

ssh user@server "df -h"
```

---

# 3. scp

`scp` (Secure Copy) transfers files securely over SSH.

---

## Copy Local File to Remote

```bash
scp file.txt user@server:/home/user/
```

---

## Copy Remote File to Local

```bash
scp user@server:/home/user/file.txt .
```

---

## Copy Directory

```bash
scp -r project user@server:/backup/
```

---

## Using SSH Port

```bash
scp -P 2222 file.txt user@server:/tmp/
```

---

# 4. curl

`curl` transfers data and is commonly used to test APIs and web servers.

---

## Get Web Page

```bash
curl https://google.com
```

---

## Show Headers

```bash
curl -I https://google.com
```

---

## Download File

```bash
curl -O https://example.com/file.zip
```

---

## API Request

```bash
curl https://api.github.com
```

---

## POST Request

```bash
curl -X POST https://example.com/api
```

---

## Script Example

```bash
#!/bin/bash

STATUS=$(curl -o /dev/null -s -w "%{http_code}" https://google.com)

echo "HTTP Status : $STATUS"
```

# 5. wget

`wget` downloads files from the internet.

---

## Download File

```bash
wget https://example.com/file.zip
```

---

## Save with Different Name

```bash
wget -O backup.zip https://example.com/file.zip
```

---

## Resume Download

```bash
wget -c https://example.com/file.zip
```

---

## Download in Background

```bash

```

---

# Difference: curl vs wget

| curl                    | wget                   |
| ----------------------- | ---------------------- |
| API testing             | File downloading       |
| Supports many protocols | Mainly HTTP/HTTPS/FTP  |
| Prints response         | Saves files by default |

# 6. netstat

`netstat` displays network connections, routing tables, and listening ports.

> **Note:** On modern Linux systems, `ss` is preferred because it is faster and actively maintained.

---

## Show All Connections

```bash
netstat -a
```

---

## Listening Ports

```bash
netstat -tuln
```

---

## Show Processes

```bash
netstat -tulpn
```

---

## Routing Table

```bash
netstat -rn
```

---

# 7. ss

`ss` (Socket Statistics) is the modern replacement for `netstat`.

---

## Show Listening Ports

```bash
ss -tuln
```

---

## Show Process Information

```bash
ss -tulpn
```

---

## Established Connections

```bash
ss -tan
```

---

## Statistics

```bash
ss -s
```

---

# Difference: netstat vs ss

| netstat                         | ss                       |
| ------------------------------- | ------------------------ |
| Older command                   | Modern command           |
| Slower                          | Faster                   |
| May require `net-tools` package | Included with `iproute2` |

---

# 8. nc (Netcat)

`nc` (Netcat) is used for:

* Port testing
* TCP/UDP connections
* Troubleshooting
* Simple data transfer

---

## Check Port

```bash
nc -zv google.com 443
```

---

## Check Multiple Ports

```bash
nc -zv localhost 22 80 443
```

---

## Listen on Port

```bash
nc -l 9000
```

---

## Send Data

Terminal 1

```bash
nc -l 9000
```

Terminal 2

```bash
echo "Hello" | nc localhost 9000
```

---

# Complete Example

```bash
#!/bin/bash

HOST="google.com"

echo "Checking Connectivity..."

if ping -c 2 "$HOST" > /dev/null
then

    echo "Network OK"

else

    echo "Network Failed"

fi

echo

echo "Checking HTTP"

curl -I https://"$HOST"
```

# Quick Summary

| Command   | Purpose                                |
| --------- | -------------------------------------- |
| `ping`    | Check connectivity                     |
| `ssh`     | Remote login                           |
| `scp`     | Secure file transfer                   |
| `curl`    | Test APIs/Web servers                  |
| `wget`    | Download files                         |
| `netstat` | View network connections (legacy)      |
| `ss`      | View network connections (recommended) |
| `nc`      | Test ports and troubleshoot networking |

---

# Best Practices

* Use **SSH keys** instead of passwords whenever possible.
* Prefer **`ss`** over `netstat` on modern Linux systems.
* Use `curl -I` to quickly verify HTTP response headers.
* Test whether a port is reachable with `nc -zv` before troubleshooting application issues.
* Use `scp` for secure file transfers instead of `ftp` or `telnet`.
* Avoid using `ping` as the only health check—some servers block ICMP while services remain available.

# Interview Questions

### 1. What is the difference between `ssh` and `scp`?

| `ssh`            | `scp`                  |
| ---------------- | ---------------------- |
| Remote login     | Secure file transfer   |
| Execute commands | Copy files/directories |

---

### 2. What is the default SSH port?

**22**

---

### 3. What is the difference between `curl` and `wget`?

| `curl`                        | `wget`                 |
| ----------------------------- | ---------------------- |
| API testing and data transfer | Downloading files      |
| Prints response by default    | Saves files by default |

---

### 4. What is the difference between `netstat` and `ss`?

* `netstat` is an older networking utility.
* `ss` is faster, more efficient, and the recommended replacement on modern Linux systems.

---

### 5. How do you check whether a server is reachable?

```bash
ping server.example.com
```

---

### 6. How do you copy a file to a remote server?

```bash
scp file.txt user@server:/path/
```

---

### 7. How do you test whether port **443** is open?

```bash
nc -zv server.example.com 443
```

---

### 8. How do you display all listening TCP and UDP ports?

```bash
ss -tuln
```

### 9. Which command is commonly used to test REST APIs?

```bash
curl
```

### 10. Why is `ss` preferred over `netstat`?

Because it is faster, consumes fewer resources, supports modern networking features, and is actively maintained as part of the `iproute2` package.
