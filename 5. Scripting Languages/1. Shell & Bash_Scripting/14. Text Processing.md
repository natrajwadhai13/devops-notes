# Module 14: Text Processing

Text processing commands are heavily used by **Linux Administrators**, **DevOps Engineers**, and **System Engineers** to search, filter, modify, and analyze text files and logs.

Common use cases:

* Log analysis
* Configuration file editing
* Data filtering
* Report generation
* Monitoring
* Automation

---

# 1. grep

`grep` searches for a specific word or pattern in a file.

## Syntax

```bash
grep "pattern" file
```

---

## Search a Word

```bash
grep "root" /etc/passwd
```

---

## Ignore Case

```bash
grep -i "linux" file.txt
```

---

## Show Line Numbers

```bash
grep -n "error" logfile.log
```

---

## Recursive Search

```bash
grep -r "Listen" /etc/httpd
```

---

## Count Matches

```bash
grep -c "error" logfile.log
```

---

## Invert Match

```bash
grep -v "root" /etc/passwd
```

---

# 2. egrep

`egrep` supports **Extended Regular Expressions (ERE)**.

> **Note:** Modern Linux systems recommend using:

```bash
grep -E
```

instead of `egrep`.

---

## Example

```bash
grep -E "error|failed" logfile.log
```

Output

```text
error
failed
```

---

# 3. cut

Extract specific columns from text.

---

## Cut Characters

```bash
echo "Linux" | cut -c1-3
```

Output

```text
Lin
```

---

## Cut Fields

```bash
cat /etc/passwd | cut -d: -f1
```

Output

```text
root
daemon
bin
```

Explanation

* `-d` → Delimiter
* `-f` → Field Number

---

# 4. awk

`awk` is a powerful text processing tool.

It processes files **column by column**.

---

## Print First Column

```bash
awk '{print $1}' file.txt
```

---

## Print First and Third Column

```bash
awk '{print $1,$3}' file.txt
```

---

## /etc/passwd Example

```bash
awk -F: '{print $1}' /etc/passwd
```

---

## Conditional Example

```bash
awk '$3>1000 {print $1}' /etc/passwd
```

---

## Sum Numbers

```bash
awk '{sum+=$1} END {print sum}' numbers.txt
```

---

# 5. sed

`sed` (Stream Editor) edits text without opening a file.

---

## Replace Text

```bash
sed 's/Linux/Docker/' file.txt
```

---

## Replace All Occurrences

```bash
sed 's/Linux/Docker/g' file.txt
```

---

## Delete Line

```bash
sed '3d' file.txt
```

---

## Print Line 5

```bash
sed -n '5p' file.txt
```

---

## Edit File Directly

```bash
sed -i 's/dev/prod/g' config.txt
```

---

# 6. sort

Sort lines alphabetically or numerically.

---

## Alphabetical Sort

```bash
sort file.txt
```

---

## Reverse Sort

```bash
sort -r file.txt
```

---

## Numeric Sort

```bash
sort -n numbers.txt
```

---

## Remove Duplicate After Sorting

```bash
sort file.txt | uniq
```

# 7. uniq

Remove consecutive duplicate lines.

---

## Example

```bash
uniq file.txt
```

---

## Count Duplicate Lines

```bash
uniq -c file.txt
```

---

## Show Only Duplicate Lines

```bash
uniq -d file.txt
```

---

# 8. tr

Translate or replace characters.

---

## Lowercase to Uppercase

```bash
echo "linux" | tr 'a-z' 'A-Z'
```

Output

```text
LINUX
```

---

## Uppercase to Lowercase

```bash
echo "LINUX" | tr 'A-Z' 'a-z'
```

---

## Delete Characters

```bash
echo "Linux123" | tr -d '0-9'
```

Output

```text
Linux
```

# 12. xargs

Convert input into command-line arguments.

---

## Example

```bash
echo "file1 file2" | xargs rm
```

Equivalent to

```bash
rm file1 file2
```

---

## Find and Delete

```bash
find . -name "*.tmp" | xargs rm
```

---

## Echo Multiple Values

```bash
echo "Linux Docker" | xargs -n1
```

Output

```text
Linux
Docker
```

---

# 13. find

Search for files and directories.

---

## Find by Name

```bash
find /home -name "*.txt"
```

---

## Find Directory

```bash
find /home -type d
```

---

## Find Files Only

```bash
find /home -type f
```

---

## Find Empty Files

```bash
find . -empty
```

---

## Find Files Larger Than 100 MB

```bash
find /var -size +100M
```

---

## Find Modified Within 7 Days

```bash
find . -mtime -7
```

---

## Find and Delete

```bash
find . -name "*.log" -delete
```

# Quick Summary

| Command   | Purpose                                  |
| --------- | ---------------------------------------- |
| `grep`    | Search text                              |
| `grep -E` | Extended regex (replacement for `egrep`) |
| `cut`     | Extract columns                          |
| `awk`     | Process text by columns                  |
| `sed`     | Edit text                                |
| `sort`    | Sort lines                               |
| `uniq`    | Remove duplicate lines                   |
| `tr`      | Translate/delete characters              |
| `wc`      | Count lines, words, characters           |
| `head`    | Show first lines                         |
| `tail`    | Show last lines                          |
| `xargs`   | Convert input into arguments             |
| `find`    | Search files/directories                 |

---

# Best Practices

* Prefer **`grep -E`** over the deprecated `egrep`.
* Use `awk` for column-based processing.
* Use `sed -i` carefully because it modifies files directly.
* Use `tail -f` to monitor logs in real time.
* Quote patterns that contain special characters:

```bash
grep "error.*failed" logfile.log
```

* Test `find` before using `-delete`:

```bash
find . -name "*.log"
```

Then, if the results are correct:

```bash
find . -name "*.log" -delete
```

# Interview Questions

### 1. What is the difference between `grep` and `grep -E`?

* `grep` uses **Basic Regular Expressions (BRE)**.
* `grep -E` uses **Extended Regular Expressions (ERE)** and replaces the older `egrep` command.

---

### 2. What is `awk` mainly used for?

To process structured text **column by column**.

---

### 3. What is the difference between `cut` and `awk`?

| `cut`                    | `awk`                                |
| ------------------------ | ------------------------------------ |
| Simple column extraction | Advanced text processing             |
| Fixed delimiters         | Conditions, calculations, formatting |

---

### 4. What does `sed -i` do?

It edits a file **in place** without creating a new output file.

---

### 5. What is the difference between `head` and `tail`?

* `head` shows the **first** lines.
* `tail` shows the **last** lines.

---

### 6. What is the purpose of `tail -f`?

To monitor a file in real time as new lines are appended, commonly used for application and system logs.

---

### 7. What does `xargs` do?

It converts input from **stdin** into command-line arguments for another command.

---

### 8. What is the difference between `find` and `grep`?

| `find`                             | `grep`                             |
| ---------------------------------- | ---------------------------------- |
| Searches for **files/directories** | Searches for **text inside files** |

> **Interview Tip:** Among these commands, **grep**, **awk**, **sed**, **find**, **tail -f**, and **xargs** are the most frequently asked in Linux, DevOps, and SRE interviews.
