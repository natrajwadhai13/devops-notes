# Module 9: Arrays

An **Array** is a collection of multiple values stored in a single variable.

Instead of creating many variables:

```bash
server1=web01
server2=web02
server3=web03
```

You can use an array:

```bash
servers=("web01" "web02" "web03")
```

Arrays are very useful in **DevOps** for storing:

* Server names
* IP addresses
* Docker containers
* Kubernetes Pods
* Users
* File names

> **Note:** Bash supports **Indexed Arrays** and **Associative Arrays** (Bash 4.0+).

---

# 1. Indexed Arrays

Indexed arrays store values using **numeric indexes**.

Index starts from **0**.

## Create an Array

```bash
fruits=("Apple" "Banana" "Mango")
```

---

## Access Elements

```bash
echo ${fruits[0]}
echo ${fruits[1]}
echo ${fruits[2]}
```

Output

```text
Apple
Banana
Mango
```

---

## Another Example

```bash
#!/bin/bash

servers=("web01" "web02" "db01")

echo "Server 1 : ${servers[0]}"
echo "Server 2 : ${servers[1]}"
echo "Server 3 : ${servers[2]}"
```

Output

```text
Server 1 : web01
Server 2 : web02
Server 3 : db01
```

---

# Initialize Array Using Index

```bash
names[0]="Linux"
names[1]="Docker"
names[2]="Kubernetes"
```

---

# Display Entire Array

```bash
echo "${names[@]}"
```

Output

```text
Linux Docker Kubernetes
```

---

# Display Indexes

```bash
echo "${!names[@]}"
```

Output

```text
0 1 2
```

---

# Array Length

Total number of elements

```bash
echo "${#names[@]}"
```

Output

```text
3
```

---

# Length of a Single Element

```bash
echo "${#names[0]}"
```

Output

```text
5
```

(`Linux` has 5 characters.)

---

# 2. Associative Arrays

Associative arrays use **keys** instead of numeric indexes.

> **Requirement:** Bash version 4 or later.

---

## Declare Associative Array

```bash
declare -A employee
```

---

## Add Values

```bash
employee[name]="Natraj"
employee[company]="Infosys"
employee[city]="Pune"
```

---

## Access Values

```bash
echo "${employee[name]}"
echo "${employee[company]}"
echo "${employee[city]}"
```

Output

```text
Natraj
Infosys
Pune
```

---

## Display All Keys

```bash
echo "${!employee[@]}"
```

Output

```text
name company city
```

---

## Display All Values

```bash
echo "${employee[@]}"
```

Output

```text
Natraj Infosys Pune
```

---

# 3. Array Operations

## Add an Element

```bash
languages=("Linux" "Docker")

languages+=("Kubernetes")

echo "${languages[@]}"
```

Output

```text
Linux Docker Kubernetes
```

---

## Update an Element

```bash
languages[1]="Ansible"

echo "${languages[@]}"
```

Output

```text
Linux Ansible Kubernetes
```

---

## Delete an Element

```bash
unset languages[1]

echo "${languages[@]}"
```

Output

```text
Linux Kubernetes
```

> **Note:** The index is removed, but the remaining indexes do not automatically shift.

Example:

```bash
echo "${!languages[@]}"
```

Output

```text
0 2
```

---

## Delete Entire Array

```bash
unset languages
```

---

## Copy an Array

```bash
array1=("Linux" "Docker")

array2=("${array1[@]}")

echo "${array2[@]}"
```

---

## Slice an Array

```bash
numbers=(10 20 30 40 50)

echo "${numbers[@]:1:3}"
```

Output

```text
20 30 40
```

Meaning:

* Start from index **1**
* Print **3 elements**

# 4. Loop Through Arrays

## Method 1 (Recommended)

```bash
#!/bin/bash

servers=("web01" "web02" "db01")

for server in "${servers[@]}"
do
    echo "$server"
done
```

Output

```text
web01
web02
db01
```

---

## Method 2 (Using Index)

```bash
#!/bin/bash

servers=("web01" "web02" "db01")

for ((i=0;i<${#servers[@]};i++))
do
    echo "${servers[$i]}"
done
```

---

## Associative Array Loop

```bash
#!/bin/bash

declare -A emp

emp[name]="Natraj"
emp[company]="Infosys"
emp[city]="Pune"

for key in "${!emp[@]}"
do
    echo "$key : ${emp[$key]}"
done
```

Output

```text
name : Natraj
company : Infosys
city : Pune
```

---

# Read User Input into an Array

```bash
#!/bin/bash

read -a skills

echo "${skills[@]}"
```

Input

```text
Linux Docker Kubernetes
```

Output

```text
Linux Docker Kubernetes
```

# Complete Example

```bash
#!/bin/bash

courses=("Linux" "Docker" "Kubernetes" "Ansible")

echo "Total Courses : ${#courses[@]}"

for course in "${courses[@]}"
do
    echo "$course"
done
```

Output

```text
Total Courses : 4

Linux
Docker
Kubernetes
Ansible
```

# Real-World DevOps Examples

## Restart Multiple Services

```bash
#!/bin/bash

services=("nginx" "docker" "ssh")

for service in "${services[@]}"
do
    systemctl restart "$service"
done
```

---

## Ping Multiple Servers

```bash
#!/bin/bash

servers=("192.168.1.10" "192.168.1.20" "192.168.1.30")

for server in "${servers[@]}"
do
    ping -c 2 "$server"
done
```

---

## Backup Multiple Directories

```bash
#!/bin/bash

dirs=("/etc" "/var/log" "/home")

for dir in "${dirs[@]}"
do
    cp -r "$dir" /backup/
done
```

# Quick Summary

| Topic             | Description                       |
| ----------------- | --------------------------------- |
| Indexed Array     | Uses numeric indexes (`0,1,2...`) |
| Associative Array | Uses string keys (`name`, `city`) |
| Add Element       | `array+=("value")`                |
| Update Element    | `array[index]="value"`            |
| Delete Element    | `unset array[index]`              |
| Delete Array      | `unset array`                     |
| Length            | `${#array[@]}`                    |
| Indexes           | `${!array[@]}`                    |
| All Values        | `${array[@]}`                     |

---

# Best Practices

* Always use **quotes** when expanding arrays:

```bash
echo "${array[@]}"
```

* Use `[@]` to access all elements.
* Use associative arrays for key-value data (configuration, environment settings).
* Use indexed arrays for ordered lists.
* Check the array length before accessing elements.
* Remember that array indexes start at **0**.

# Interview Questions

### 1. What is an array in Bash?

An array is a variable that stores multiple values under a single name.

### 2. What is the difference between an indexed array and an associative array?

| Indexed Array        | Associative Array     |
| -------------------- | --------------------- |
| Uses numeric indexes | Uses string keys      |
| Starts at index `0`  | Keys are user-defined |
| Example: `arr[0]`    | Example: `emp[name]`  |

### 3. How do you declare an associative array?

```bash
declare -A emp
```

### 4. How do you print all array elements?

```bash
echo "${array[@]}"
```

### 5. How do you find the number of elements in an array?

```bash
echo "${#array[@]}"
```

### 6. How do you delete an array element?

```bash
unset array[index]
```

### 7. How do you loop through an array?

```bash
for item in "${array[@]}"
do
    echo "$item"
done
```

### 8. What is the difference between `${array[@]}` and `${array[*]}`?

* **`${array[@]}`**: Treats each array element as a separate item (recommended, especially with quotes).
* **`${array[*]}`**: Treats all elements as a single string when quoted.

> **Interview Tip:** In almost all Bash scripts, prefer **`${array[@]}`** because it correctly preserves elements containing spaces.
