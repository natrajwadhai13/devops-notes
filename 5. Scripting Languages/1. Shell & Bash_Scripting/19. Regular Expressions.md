# Module 19: Regular Expressions (Regex)

A **Regular Expression (Regex)** is a sequence of special characters used to **search, match, validate, and manipulate text**.

Regex is commonly used with commands like:

* `grep`
* `sed`
* `awk`
* `find`
* `perl`

## Real-World Uses

* Search log files
* Validate email addresses
* Find IP addresses
* Filter usernames
* Replace text
* Parse configuration files

---

# What is Regex?

Instead of searching for an exact word:

```text
Linux
```

Regex allows searching using patterns:

```text
L.*
```

Matches:

```text
Linux
LinuxAdmin
Linux123
```

---

# Regex Basics

## Common Regex Symbols

| Symbol  | Meaning                                  | Example   |
| ------- | ---------------------------------------- | --------- |
| `.`     | Any single character                     | `L.nux`   |
| `*`     | Zero or more occurrences                 | `ab*`     |
| `+`     | One or more occurrences (Extended Regex) | `ab+`     |
| `?`     | Zero or one occurrence (Extended Regex)  | `colou?r` |
| `^`     | Beginning of line                        | `^root`   |
| `$`     | End of line                              | `bash$`   |
| `[]`    | Character class                          | `[abc]`   |
| `[^]`   | Negated character class                  | `[^0-9]`  |
| `[a-z]` | Lowercase letters                        | `[a-z]`   |
| `[A-Z]` | Uppercase letters                        | `[A-Z]`   |
| `[0-9]` | Digits                                   | `[0-9]`   |
| `\`     | Escape special character                 | `\.`      |

```text
ac
```

Matches

## End of Line


Matches


```text

```

Matches


## Letters


---

```bash id="nkjjlwm"

```

---

## Replace All Matches


## Replace Beginning of Line


---

## Replace End of Line

```bash id="jlwm67"

```

---

## Delete Blank Lines

```bash id="jlwm23"

```

---

## Print Matching Lines

```bash id="jlwm87"

```

---

## Delete Matching Lines

```bash id="jlwm43"

```

---

## Replace Numbers


# Common Regex Patterns

| Pattern    | Matches                             |
| ---------- | ----------------------------------- |
| `^Linux`   | Starts with Linux                   |
| `bash$`    | Ends with bash                      |
| `L.*x`     | Starts with L, ends with x          |
| `[0-9]`    | One digit                           |
| `[A-Z]`    | Uppercase letter                    |
| `[a-z]`    | Lowercase letter                    |
| `[A-Za-z]` | Any letter                          |
| `[0-9]+`   | One or more digits (Extended Regex) |
| `^$`       | Empty line                          |
| `.`        | Any single character                |
| `.*`       | Zero or more characters             |

# Best Practices

* Use **`grep -E`** instead of the deprecated `egrep`.
* Quote regex patterns to prevent shell expansion:

```bash id="jlwm53"
grep "^[0-9]" file.txt
```

* Use `^` and `$` to match complete lines instead of partial matches.
* Test regex patterns on sample data before using them on production logs.
* Use `awk` when regex matching also requires field-based processing.

# Interview Questions

### 1. What is a Regular Expression (Regex)?

A Regular Expression is a pattern used to search, match, validate, or manipulate text.

---

### 2. What do `^` and `$` mean in Regex?

* `^` → Matches the **beginning** of a line.
* `$` → Matches the **end** of a line.

---

### 3. What does `.` represent?

It matches **any single character** except a newline.

---

### 4. What does `.*` mean?

* `.` matches any single character.
* `*` means zero or more occurrences.

Together, `.*` matches **zero or more of any characters**.

---

### 5. What is the difference between `grep` and `grep -E`?

* `grep` uses **Basic Regular Expressions (BRE)**.
* `grep -E` uses **Extended Regular Expressions (ERE)**, supporting operators like `+`, `?`, and `|` without escaping.

---

### 6. How do you replace text using `sed`?

```bash id="jlwm39"
sed 's/old/new/g' file.txt
```

---

### 7. How do you search using Regex in `awk`?

```bash id="jlwm41"
awk '/pattern/' file.txt
```

---

### 8. Which Regex pattern matches one or more digits?

```text
[0-9]+
```

(Used with **Extended Regular Expressions**, for example `grep -E`.)

---

### 9. What is the difference between `*` and `+`?

| Symbol | Meaning                                  |
| ------ | ---------------------------------------- |
| `*`    | Zero or more occurrences                 |
| `+`    | One or more occurrences (Extended Regex) |

> **Interview Tip:** The most frequently asked Regex topics are:
>
> * `^`, `$`, `.`, `*`, `+`, `?`
> * Character classes (`[0-9]`, `[A-Z]`, `[a-z]`)
> * `grep` vs `grep -E`
> * Regex with `sed` and `awk`
> * Searching logs and replacing configuration values using regular expressions
