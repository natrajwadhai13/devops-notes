# Module 21: DevOps Automation

DevOps Automation means using Shell Scripts to automate repetitive DevOps tasks such as:

* Code Deployment
* Git Operations
* Docker Management
* Kubernetes Operations
* Jenkins Automation
* Health Checks
* Backups
* Server Monitoring

Automation reduces:

* Manual work
* Human errors
* Deployment time
* Downtime

# 1. Git Automation

Shell scripts can automate Git operations.

---

## Git Pull

```bash
#!/bin/bash

cd /home/user/project || exit 1

git pull origin main
```

---

## Git Add, Commit & Push

```bash

git push origin main
```

## Check Git Status

```bash
#!/bin/bash

git status

git branch

git log --oneline -5
```

---

## Clone Repository

```bash

```

# 2. Docker Automation

Automate Docker image build, container creation, cleanup, and deployment.

---

## Build Docker Image

```bash
#!/bin/bash

docker build -t myapp:v1 .
```

---

## Run Container

```bash
docker run -d \
--name myapp \
-p 8080:80 \
myapp:v1
```

---

## Stop & Remove Container

```bash
docker stop myapp

docker rm myapp
```

---

## Build + Run

```bash
#!/bin/bash

docker build -t myapp .

docker rm -f myapp 2>/dev/null

docker run -d \
--name myapp \
-p 8080:80 \
myapp
```

---

## Docker Cleanup

```bash
docker system prune -af
```

# 5. Backup Script

Create automatic backups.

---

## Backup Directory

```bash
#!/bin/bash

SOURCE="/home/user/project"

DEST="/backup"

DATE=$(date +%F)

mkdir -p "$DEST"

cp -r "$SOURCE" "$DEST/project_$DATE"

echo "Backup Completed"
```

---

## Compressed Backup

```bash
#!/bin/bash

tar -czf backup_$(date +%F).tar.gz /home/user/project
```

---

## Backup Database

```bash
mysqldump database > backup.sql
```

# 6. Health Check Script

Monitor server health.

---

## Complete Script

```bash
#!/bin/bash

echo "========== Health Report =========="

echo
echo "Hostname"
hostname

echo
echo "Date"
date

echo
echo "Disk Usage"
df -h

echo
echo "Memory"
free -h

echo
echo "CPU Load"
uptime

echo
echo "Running Services"

systemctl is-active nginx

systemctl is-active docker
```

---

## Check Website

```bash
#!/bin/bash

URL="https://example.com"

STATUS=$(curl -s -o /dev/null -w "%{http_code}" "$URL")

if [ "$STATUS" -eq 200 ]
then
    echo "Website UP"
else
    echo "Website DOWN"
fi
```

---

## Check Multiple Servers

```bash
#!/bin/bash

servers=("server1" "server2" "server3")

for server in "${servers[@]}"
do

    ping -c 2 "$server"

done
```

# Best Practices

* Always check the exit status of critical commands:

```bash
git pull origin main || exit 1
```

* Store configurable values (image names, namespaces, repository URLs) in variables.
* Use timestamps in backup file names to avoid overwriting previous backups.
* Wait for Kubernetes rollouts to complete using:

```bash
kubectl rollout status deployment/myapp
```

* Redirect deployment logs to a file for troubleshooting.
* Validate application health after deployment before declaring success.

# Interview Questions

### 1. Why is Shell Scripting used in DevOps?

To automate repetitive tasks such as deployments, backups, monitoring, and infrastructure management.

---

### 2. How do you automate a Git pull?

```bash
git pull origin main
```

---

### 3. Which command builds a Docker image?

```bash
docker build -t myapp .
```

---

### 4. Which command deploys resources to Kubernetes?

```bash
kubectl apply -f deployment.yaml
```

---

### 5. How do you restart a Kubernetes deployment?

```bash
kubectl rollout restart deployment myapp
```

---

### 6. How do you check whether a Kubernetes deployment completed successfully?

```bash
kubectl rollout status deployment/myapp
```

---

### 7. What is the purpose of a health check script?

To verify that servers, services, or applications are running correctly after deployment or during regular monitoring.

---

### 8. Why are backup scripts important?

They automate data protection and make recovery possible in case of failures, corruption, or accidental deletion.

---

### 9. How does Jenkins execute shell scripts?

Typically by running a shell build step or pipeline stage, for example:

```bash
chmod +x deploy.sh
./deploy.sh
```

---

```text
   ↓

   ↓
Docker Build
   ↓
Push Docker Image
   ↓
Deploy to Kubernetes
   ↓
Health Check
   ↓
Deployment Complete
```
