# Module 22: Advanced Bash

Advanced Bash features make scripts more powerful, readable, and efficient.

These features are commonly used in:

* DevOps Automation
* CI/CD Pipelines
* Linux Administration
* System Monitoring
* Production Scripts

# 1. Command Substitution

Command substitution stores the output of a command in a variable.

---

## Modern Syntax (Recommended)

```bash id="m62n4h"
current_date=$(date)

echo "$current_date"
```

---

## Old Syntax

```bash id="65vjbm"
current_date=`date`
```

The old syntax works but `$(...)` is recommended.

---

## Example

```bash id="t9vcjx"
#!/bin/bash

hostname=$(hostname)

echo "Server : $hostname"
```

Output

```text id="ojk31i"
Server : server01
```

---

## Nested Commands

```bash id="7xwwrg"
echo "$(whoami) is logged into $(hostname)"
```

---

# 2. Arithmetic Expansion

Perform mathematical calculations.

---

## Syntax

```bash id="ow1p8q"
$((expression))
```

---

## Example

```bash id="6c6kr0"
a=20

b=10

echo $((a+b))
```

Output

```text id="78yphm"
30
```

---

## More Examples

```bash id="6u8wkx"
echo $((10*5))

echo $((20/4))

echo $((25%7))
```

---

## Increment

```bash id="sqarf0"
count=10

((count++))

echo "$count"
```

# 5. Here Document

Provides multi-line input to a command.

---

## Syntax

```bash id="jlwm10"
command <<EOF

Text

EOF
```

---

## Example

```bash id="jlwm13"
cat <<EOF
Linux
Docker
Kubernetes
EOF
```

Output

```text id="jlwm14"
Linux
Docker
Kubernetes
```

---

## Write to File

```bash id="jlwm16"
cat > info.txt <<EOF
Linux
Docker
Jenkins
EOF
```

---

## Variable Expansion

```bash id="jlwm17"
name="Natraj"

cat <<EOF
Hello $name
EOF
```

Output

```text id="jlwm18"
Hello Natraj
```

---

# 6. Here String

Pass a single string as input.

---

## Syntax

```bash id="jlwm19"
command <<< "text"
```

---

## Example

```bash id="jlwm20"
grep Linux <<< "Linux Docker Kubernetes"
```

Output

```text id="jlwm21"
Linux Docker Kubernetes
```

---

## Read Variable

```bash id="jlwm22"
read name <<< "Natraj"

echo "$name"
```

---

# Difference: Here Document vs Here String

| Here Document     | Here String       |
| ----------------- | ----------------- |
| Multi-line input  | Single-line input |
| `<<EOF`           | `<<<`             |
| Large text blocks | Small input       |

# 7. source Command

Executes another script in the **current shell**.

Changes remain available after execution.

---

## Syntax

```bash id="jlwm23"
source script.sh
```

or

```bash id="jlwm24"
. script.sh
```

---

## Example

`variables.sh`

```bash id="jlwm25"
NAME="Linux"
```

Main Script

```bash id="jlwm26"
source variables.sh

echo "$NAME"
```

Output

```text id="jlwm27"
Linux
```

---

# Difference: source vs bash

| source           | bash                           |
| ---------------- | ------------------------------ |
| Current shell    | New shell                      |
| Variables remain | Variables disappear after exit |

# 9. Shell Options

Control Bash behavior.

---

## Show Options

```bash id="jlwm36"
set -o
```

---

## Enable Nounset

```bash id="jlwm37"
set -u
```

Stops use of undefined variables.

---

## Enable Pipefail

```bash id="jlwm38"
set -o pipefail
```

Pipeline fails if any command fails.

---

## Enable Verbose

```bash id="jlwm39"
set -v
```

---

## Enable Debug

```bash id="jlwm40"
set -x
```

---

## Production Recommendation

```bash id="jlwm42"
set -euo pipefail
```

Meaning

* `-e` → Exit on error
* `-u` → Undefined variables are errors
* `pipefail` → Pipeline fails if any command fails

# 11. Named Pipes (FIFO)

Named Pipes allow communication between two processes.

---

## Create FIFO

```bash id="jlwm48"
mkfifo mypipe
```

---

## Terminal 1

```bash id="jlwm50"
cat mypipe
```

---

## Terminal 2

```bash id="jlwm51"
echo "Hello Linux" > mypipe
```

Output

```text id="jlwm52"
Hello Linux
```

---

## Remove FIFO

```bash id="jlwm54"
rm mypipe
```

# Best Practices

* Prefer `$(command)` over backticks (`` `command` ``) for command substitution.
* Use `set -euo pipefail` at the beginning of production scripts for safer error handling.
* Use `source` when you need variables or functions to remain available in the current shell.
* Use Here Documents (`<<EOF`) for generating configuration files or multi-line content.
* Always remove temporary FIFOs and files with `trap` to avoid resource leaks.
* Keep aliases in `~/.bashrc` for permanent availability.

# Interview Questions

### 1. What is command substitution?

It executes a command and substitutes its output.

```bash id="’wini63"
date=$(date)
```

---

### 2. What is the difference between `$( )` and `$(( ))`?

| `$( )`            | `$(( ))`                         |
| ----------------- | -------------------------------- |
| Executes commands | Performs arithmetic calculations |

---

### 3. What is brace expansion?

It generates multiple strings without using loops.

Example:

```bash id="’wini64"
echo {1..5}
```

---

### 4. What is process substitution?

It treats the output of a command as if it were a file.

Example:

```bash id="’wini65"
diff <(ls dir1) <(ls dir2)
```

---

### 5. What is the difference between a Here Document and a Here String?

| Here Document    | Here String       |
| ---------------- | ----------------- |
| Multi-line input | Single-line input |
| `<<EOF`          | `<<<`             |

---

### 6. What is the difference between `source` and `bash`?

| `source`                             | `bash`                                                 |
| ------------------------------------ | ------------------------------------------------------ |
| Runs in the current shell            | Starts a new shell                                     |
| Variables/functions remain available | Variables/functions disappear when the new shell exits |

---

### 7. Why is `set -euo pipefail` recommended?

Because it:

* Stops execution on errors (`-e`)
* Prevents use of undefined variables (`-u`)
* Detects failures anywhere in a pipeline (`pipefail`)

---

### 8. What is the purpose of `trap`?

It executes a command when a signal is received or when the script exits, making it useful for cleanup and graceful shutdown.

---

### 9. What is a Named Pipe (FIFO)?

A special file that allows two or more processes to communicate by passing data between them.

---

### 10. Where should permanent aliases be stored?

In the user's Bash configuration file:

```text id="’wini66"
~/.bashrc
```

Then reload it with:

```bash id="’wini67"
source ~/.bashrc
```

> **Interview Tip:** The most frequently asked Advanced Bash topics are:

> * `source` vs `bash`
> * Here Document (`<<EOF`) vs Here String (`<<<`)
> * `set -euo pipefail`
> * `trap`
