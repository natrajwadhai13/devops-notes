# Module 10: Strings

A **String** is a sequence of characters enclosed in single (`'`) or double (`"`) quotes.

Strings are commonly used for:

* Usernames
* File names
* Paths
* URLs
* Log messages
* Configuration values

---

# Creating Strings

## Double Quotes

Variables are expanded.

```bash
name="Natraj"

echo "Hello $name"
```

Output

```text
Hello Natraj
```

---

## Single Quotes

Variables are **not** expanded.

```bash
name="Natraj"

echo 'Hello $name'
```

Output

```text
Hello $name
```

---

# 1. String Length

Use `${#variable}` to find the length of a string.

## Syntax

```bash
echo ${#string}
```

---

## Example

```bash
#!/bin/bash

name="Linux"

echo ${#name}
```

Output

```text
5
```

---

## Another Example

```bash
text="Shell Scripting"

echo "Length : ${#text}"
```

Output

```text
Length : 16
```

---

# 2. String Concatenation

Concatenation means joining two or more strings.

## Method 1

```bash
first="Linux"
second="Admin"

result="$first $second"

echo "$result"
```

Output

```text
Linux Admin
```

---

## Method 2

```bash
name="Natraj"

echo "Hello $name, Welcome!"
```

Output

```text
Hello Natraj, Welcome!
```

---

## Method 3

```bash
path="/home"
folder="/backup"

echo "$path$folder"
```

Output

```text
/home/backup
```

---

# 3. Substring

Extract a portion of a string.

## Syntax

```bash
${string:start:length}
```

---

## Example

```bash
text="ShellScripting"

echo "${text:0:5}"
```

Output

```text
Shell
```

---

## Another Example

```bash
text="Linux Docker Kubernetes"

echo "${text:6:6}"
```

Output

```text
Docker
```

---

## Last Characters

```bash
text="Natraj"

echo "${text: -3}"
```

Output

```text
raj
```

> **Note:** There must be a space before `-3`.

---

# 4. Replace Text

Replace part of a string.

## Syntax

```bash
${string/old/new}
```

---

## Replace First Match

```bash
text="I like Linux"

echo "${text/Linux/Docker}"
```

Output

```text
I like Docker
```

---

## Replace All Matches

```bash
text="Linux Linux Linux"

echo "${text//Linux/Docker}"
```

Output

```text
Docker Docker Docker
```

---

## Remove Text

```bash
text="HelloWorld"

echo "${text/World/}"
```

Output

```text
Hello
```

---

# 5. Uppercase

Convert a string to uppercase.

## Syntax

```bash
${string^^}
```

---

## Example

```bash
name="linux"

echo "${name^^}"
```

Output

```text

```

---

## First Character Only

```bash
name="docker"

echo "${name^}"
```

Output

```text

```

# 6. Lowercase

Convert a string to lowercase.

## Syntax

```bash
${string,,}
```

---

## Example

```bash
name="KUBERNETES"

echo "${name,,}"
```

Output

```text

```

---

## First Character Only

```bash
name="LINUX"

echo "${name,}"
```

Output

```text
lINUX
```

# 7. Pattern Matching

Pattern matching is used to compare strings using wildcard patterns.

Common wildcards:

| Pattern | Meaning                         |
| ------- | ------------------------------- |
| `*`     | Zero or more characters         |
| `?`     | Exactly one character           |
| `[abc]` | Any one character from the list |
| `[0-9]` | Any digit                       |
| `[a-z]` | Any lowercase letter            |

---

## Using `[[ ]]`

```bash
name="Linux"

if [[ "$name" == L* ]]
then
    echo "Starts with L"
fi
```

Output

```text
Starts with L
```

---

## Ends With

```bash
file="backup.sh"

if [[ "$file" == *.sh ]]
then
    echo "Shell Script"
fi
```

Output

```text
Shell Script
```

---

## Contains Text

```bash
text="Welcome to Linux"

if [[ "$text" == *Linux* ]]
then
    echo "Found"
fi
```

Output

```text
Found
```

---

## Match One Character

```bash
value="cat"

if [[ "$value" == c?t ]]
then
    echo "Matched"
fi
```

Output

```text
Matched
```

---

## Match Digits

```bash
number="5"

if [[ "$number" == [0-9] ]]
then
    echo "Digit"
fi
```

---

## Match Lowercase Letters

```bash
letter="a"

if [[ "$letter" == [a-z] ]]
then
    echo "Lowercase Letter"
fi
```

# Remove Characters Using Patterns

## Remove Prefix

```bash
file="/home/user/file.txt"

echo "${file#/home/}"
```

Output

```text
user/file.txt
```

---

## Remove Longest Prefix

```bash
file="/home/user/file.txt"

echo "${file##*/}"
```

Output

```text
file.txt
```

---

## Remove Suffix

```bash
file="backup.tar.gz"

echo "${file%.gz}"
```

Output

```text
backup.tar
```

---

## Remove Longest Suffix

```bash
file="backup.tar.gz"

echo "${file%%.*}"
```

Output

```text
backup
```

# Complete Example

```bash
#!/bin/bash

name="linux"

echo "Original   : $name"
echo "Length     : ${#name}"
echo "Uppercase  : ${name^^}"
echo "Lowercase  : ${name,,}"

new="${name} Admin"

echo "Combined   : $new"

echo "Substring  : ${new:0:5}"
```

Output

```text
Original   : linux
Length     : 5
Uppercase  : LINUX
Lowercase  : linux
Combined   : linux Admin
Substring  : linux
```

# Quick Summary

| Operation     | Syntax                 |
| ------------- | ---------------------- |
| Length        | `${#str}`              |
| Concatenation | `"$str1$str2"`         |
| Substring     | `${str:start:length}`  |
| Replace First | `${str/old/new}`       |
| Replace All   | `${str//old/new}`      |
| Uppercase     | `${str^^}`             |
| Lowercase     | `${str,,}`             |
| Starts With   | `[[ $str == text* ]]`  |
| Ends With     | `[[ $str == *.txt ]]`  |
| Contains      | `[[ $str == *text* ]]` |

---

# Best Practices

* Always quote string variables:

```bash
echo "$name"
```

* Use `[[ ]]` for string comparisons and pattern matching.
* Use parameter expansion instead of external commands (`cut`, `awk`, `sed`) for simple string operations because it is faster.
* Use meaningful variable names (`username`, `filename`, `logfile`).
* Convert user input to lowercase when comparisons should be case-insensitive.

```bash
result="$str1$str2"
```

Replace all occurrences:


```bash
${string^^}
```

---

### 6. How do you convert a string to lowercase?

```bash
${string,,}
```

---

### 7. Which wildcard matches any number of characters?

`*`

---

### 8. Which wildcard matches exactly one character?

`?`

---

### 9. Why is `[[ ]]` preferred for pattern matching?

Because it supports wildcard matching (`*`, `?`, character classes), is Bash-specific, and is safer than `[ ]` for string comparisons.
