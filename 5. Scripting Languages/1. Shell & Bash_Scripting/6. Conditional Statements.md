# Module 6: Conditional Statements

Conditional statements allow a script to make decisions based on conditions.

They are widely used for:

- User validation
- File checking
- Backup scripts
- Service monitoring
- DevOps automation
- Error handling

---

# 1. if Statement

The `if` statement executes a block of code only when the condition is **true**.

## Syntax

```bash
if [ condition ]
then
    commands
fi
```

---

## Example 1

```bash
#!/bin/bash

num=10

if [ $num -gt 5 ]
then
    echo "Number is Greater than 5"
fi
```

**Output**

```text
Number is Greater than 5
```

---

## Example 2

```bash
#!/bin/bash

read -p "Enter Age: " age

if [ $age -ge 18 ]
then
    echo "Eligible to Vote"
fi
```

---

# 2. if-else Statement

Executes one block if the condition is true; otherwise executes another block.

## Syntax

```bash
if [ condition ]
then
    commands
else
    commands
fi
```

---

## Example

```bash
#!/bin/bash

read -p "Enter Number: " num

if [ $num -eq 10 ]
then
    echo "Correct Number"
else
    echo "Wrong Number"
fi
```

Output

```text
Enter Number: 5

Wrong Number
```

---

# 3. elif Statement

Used when multiple conditions need to be checked.

## Syntax

```bash
if [ condition ]
then
    commands

elif [ condition ]
then
    commands

else
    commands
fi
```

---

## Example

```bash
#!/bin/bash

read -p "Enter Marks: " marks

if [ $marks -ge 90 ]
then
    echo "Grade A"

elif [ $marks -ge 75 ]
then
    echo "Grade B"

elif [ $marks -ge 50 ]
then
    echo "Grade C"

else
    echo "Fail"
fi
```

---

## Output

```text
Marks : 82

Grade B
```

---

# 4. Nested if

An `if` statement inside another `if`.

## Syntax

```bash
if [ condition ]
then
    if [ condition ]
    then
        commands
    fi
fi
```

---

## Example

```bash
#!/bin/bash

read -p "Enter Username: " user
read -s -p "Enter Password: " pass

echo

if [ "$user" = "admin" ]
then

    if [ "$pass" = "linux123" ]
    then
        echo "Login Successful"
    else
        echo "Wrong Password"
    fi

else
    echo "Invalid User"
fi
```

---

# 5. test Command

The `test` command checks a condition.

It is equivalent to `[ ]`.

### Syntax

```bash
test condition
```

or

```bash
[ condition ]
```

---

## Example

```bash
#!/bin/bash

num=20

if test $num -gt 10
then
    echo "Greater"
fi
```

---

## Equivalent

```bash
if [ $num -gt 10 ]
then
    echo "Greater"
fi
```

Both produce the same result.

---

# 6. `[ ]` (Single Bracket)

`[ ]` is another way to write the `test` command.

Supports:

- Numeric comparison
- String comparison
- File testing

---

## Example

```bash
#!/bin/bash

num=100

if [ $num -eq 100 ]
then
    echo "Matched"
fi
```

---

## File Example

```bash
if [ -f "/etc/passwd" ]
then
    echo "File Exists"
fi
```

---

# 7. `[[ ]]` (Double Bracket)

`[[ ]]` is an advanced Bash conditional expression.

It is safer and supports additional features.

### Advantages

- Supports `&&` and `||`
- Better string comparison
- Pattern matching
- Handles spaces more safely
- No pathname expansion issues

---

## Example

```bash
#!/bin/bash

age=25

if [[ $age -ge 18 && $age -le 60 ]]
then
    echo "Eligible"
fi
```

---

## String Example

```bash
#!/bin/bash

name="Linux"

if [[ "$name" == "Linux" ]]
then
    echo "Matched"
fi
```

---

# `[ ]` vs `[[ ]]`

| `[ ]`                                    | `[[ ]]`                        |     |            |
| ---------------------------------------- | ------------------------------ | --- | ---------- |
| POSIX standard                           | Bash-specific                  |     |            |
| Uses `test` command                      | Bash keyword                   |     |            |
| Limited features                         | Advanced features              |     |            |
| Logical operators require separate tests | Supports `&&` and `            |     | ` directly |
| Less safe with special characters        | Safer and recommended for Bash |     |            |

# 8. case Statement

The `case` statement is used when there are multiple possible values for a single variable.

It is easier to read than many `elif` conditions.

---

## Syntax

```bash
case variable in

value1)
    commands
    ;;

value2)
    commands
    ;;

*)
    default command
    ;;

esac
```

---

## Example 1

```bash
#!/bin/bash

read -p "Enter Choice (1-3): " choice

case $choice in

1)
    echo "Linux"
    ;;

2)
    echo "Docker"
    ;;

3)
    echo "Kubernetes"
    ;;

*)
    echo "Invalid Choice"
    ;;

esac
```

Output

```text
Enter Choice : 2

Docker
```

---

## Example 2 (Menu)

```bash
#!/bin/bash

echo "1. Start"
echo "2. Stop"
echo "3. Restart"

read -p "Select Option: " option

case $option in

1)
    echo "Starting Service..."
    ;;

2)
    echo "Stopping Service..."
    ;;

3)
    echo "Restarting Service..."
    ;;

*)
    echo "Invalid Option"
    ;;

esac
```

---

# Complete Example

```bash
#!/bin/bash

read -p "Enter Username: " username

if [[ "$username" == "admin" ]]
then
    echo "Welcome Admin"

elif [[ "$username" == "guest" ]]
then
    echo "Welcome Guest"

else
    echo "Unknown User"
fi
```

# Quick Summary

| Statement   | Purpose                             |
| ----------- | ----------------------------------- |
| `if`        | Execute code when condition is true |
| `if-else`   | Choose between two blocks           |
| `elif`      | Check multiple conditions           |
| `Nested if` | Place an `if` inside another `if`   |
| `test`      | Evaluate a condition                |
| `[ ]`       | Standard condition test             |
| `[[ ]]`     | Advanced Bash condition test        |
| `case`      | Handle multiple choices efficiently |

---

# Best Practices

- Prefer **`[[ ]]`** over **`[ ]`** in Bash scripts.
- Quote string variables:

```bash
if [[ "$name" == "Linux" ]]
```

- Use `case` instead of long `if-elif` chains when checking a single variable against many values.
- Keep conditions simple and readable.
- Always close blocks correctly:
  - `fi` for `if`
  - `esac` for `case`

# Interview Questions

### 1. What is the purpose of the `if` statement?

It executes a block of code only if the specified condition is true.

### 2. What is the difference between `if-else` and `elif`?

- `if-else` handles two outcomes (true/false).
- `elif` allows checking multiple conditions sequentially.

### 3. What is a nested `if` statement?

An `if` statement placed inside another `if` statement.

### 4. What is the `test` command?

It evaluates a condition and is equivalent to using `[ ]`.

### 5. What is the difference between `[ ]` and `[[ ]]`?

- `[ ]` is POSIX-compliant and provides basic condition testing.
- `[[ ]]` is Bash-specific, safer, and supports advanced features like `&&`, `||`, and pattern matching.

### 6. When should you use a `case` statement?

Use `case` when comparing one variable against multiple possible values, as it is cleaner than a long `if-elif-else` chain.

### 7. Which closing keywords are used for conditional blocks?

- `fi` closes an `if` block.
- `esac` closes a `case` block.
