# Module 11: File Handling

File handling is one of the most important topics in Shell Scripting.

It is used for:

- Reading configuration files
- Creating log files
- Backups
- Log analysis
- Report generation
- DevOps automation

---

# Check File Exists

Use file test operators to verify whether a file or directory exists.

## Check File Exists (`-f`)

```bash
#!/bin/bash

file="test.txt"

if [ -f "$file" ]
then
    echo "File Exists"
else
    echo "File Not Found"
fi
```

Output

```text
File Exists
```

---

## Check Directory Exists (`-d`)

```bash
dir="/home/natraj"

if [ -d "$dir" ]
then
    echo "Directory Exists"
fi
```

---

## Check File or Directory Exists (`-e`)

```bash
if [ -e "test.txt" ]
then
    echo "Exists"
fi
```

## Remove File


## Force Delete

```bash

```

---

## Delete Multiple Files

```bash

```

---

## Delete Directory

Empty directory

```bash
rmdir test
```

Directory with files

```bash
rm -r test
```

Force delete

```bash
rm -rf test
```

⚠️ **Warning:** Be very careful with:

```bash
rm -rf /
```

or

```bash
rm -rf *
```

These commands can delete critical files.

# Difference: `>` vs `>>`

| Operator | Purpose             |
| -------- | ------------------- |
| `>`      | Overwrites the file |
| `>>`     | Appends to the file |

Example

```bash
echo "Linux" > test.txt
echo "Docker" > test.txt
```

Output

```text
Docker
```

---

```bash
echo "Linux" > test.txt
echo "Docker" >> test.txt
```

Output

```text
Linux
Docker
```

# File Permissions

View permissions

```bash
ls -l demo.txt
```

Example

```text
-rw-r--r-- 1 root root 100 Jul 24 demo.txt
```

---

## Permission Meaning

```text
-rwxr-xr--
```

| Symbol | Meaning       |
| ------ | ------------- |
| `r`    | Read          |
| `w`    | Write         |
| `x`    | Execute       |
| `-`    | No Permission |

---

## Change Permissions

Using symbolic mode

```bash
chmod +x script.sh
chmod -w demo.txt
chmod u+r demo.txt
chmod g+w demo.txt
chmod o-r demo.txt
```

---

Using numeric mode

```bash
chmod 755 script.sh
chmod 644 demo.txt
chmod 777 demo.txt
```

---

## Common Permission Values

| Permission | Meaning                           |
| ---------- | --------------------------------- |
| 777        | Read, Write, Execute for everyone |
| 755        | Owner: RWX, Group: RX, Others: RX |
| 744        | Owner: RWX, Group: R, Others: R   |
| 700        | Owner only                        |
| 644        | Owner: RW, Group: R, Others: R    |
| 600        | Owner: RW only                    |

# Backup Script

## Simple Backup

```bash
#!/bin/bash

SOURCE="/home/natraj/data"

DEST="/backup"

cp -r "$SOURCE" "$DEST"

echo "Backup Completed"
```

---

## Backup with Date

```bash
#!/bin/bash

SOURCE="/home/natraj/data"

DEST="/backup"

DATE=$(date +%F)

cp -r "$SOURCE" "$DEST/backup_$DATE"

echo "Backup Created Successfully"
```

Example Output

```text
backup_2026-07-24
```

---

## Backup with Timestamp

```bash
#!/bin/bash

timestamp=$(date +"%Y%m%d_%H%M%S")

cp -r project "project_$timestamp"
```

Example

```text
project_20260724_103522
```

# Complete Example

```bash
#!/bin/bash

FILE="demo.txt"

if [ ! -f "$FILE" ]
then
    touch "$FILE"
fi

echo "Linux" > "$FILE"

echo "Docker" >> "$FILE"

echo "Kubernetes" >> "$FILE"

echo "========== File Content =========="

cat "$FILE"

echo

echo "Size"

ls -lh "$FILE"
```

Output

```text
========== File Content ==========

Linux
Docker
Kubernetes

-rw-r--r-- 1 root root 25 Jul 24 demo.txt
```

# Best Practices

- Always quote file names:

```bash
cp "$source" "$destination"
```

- Check whether a file exists before reading or deleting it.
- Use `while read` instead of `cat` in scripts for processing files line by line.
- Use `>>` when you want to preserve existing data.
- Never use `chmod 777` unless absolutely necessary.
- Test `rm -rf` commands carefully before executing them.

# Interview Questions

### 1. How do you check whether a file exists?

```bash
if [ -f file.txt ]
```

---

### 2. What is the difference between `>` and `>>`?

- `>` overwrites the file.
- `>>` appends to the existing file.

---

### 3. Which command creates an empty file?

```bash
touch file.txt
```

---

### 4. Which command reads a file line by line?

```bash
while read line
do
    echo "$line"
done < file.txt
```

---

### 5. How do you change file permissions?

```bash
chmod 755 script.sh
```

---

### 6. How do you check a file's size?

```bash
ls -lh file.txt
```

or

```bash
du -sh file.txt
```

---

### 7. Which command copies files and directories?

```bash
cp
```

Use `-r` for directories.

---

### 8. Why is `chmod 777` generally discouraged?

Because it gives **read, write, and execute permissions to everyone**, creating a significant security risk. Prefer the minimum permissions required, such as `755` or `644`, depending on the use case.
